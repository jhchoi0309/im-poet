# 0.8.2.2 호환성과 실행 기록

Windows, macOS, Linux에서 Codex CLI, Claude Code, Gemini CLI를 쓰는 아홉 조합을 검사 대상으로 둔다. 운영체제와 프로세서의 지원 범위는 각 CLI를 따른다. 설치기와 보조 도구는 Python 3.10 이상과 표준 라이브러리를 쓰고, 핵심 윤문 지침은 텍스트로 읽을 수 있다.

## 검증 단계

| 단계 | 실제로 확인하는 것 |
| --- | --- |
| 패키지 설치 | 경로와 UTF-8 파일, 버전과 지문, 전체 파일의 일치 |
| 갱신 | 내용이 다른 이전 설치를 백업 없이 교체, 임시 이전 폴더 정리, 다른 스킬 보존 |
| 보조 도구 | 설치된 문자 검사와 바이트 계산, 표면 비교 도구의 실행 |
| CLI 시작 | 고정한 제공자 CLI의 `--version` |
| 스킬 인식 | CLI가 찾아낸 스킬의 이름과 경로, 활성 상태 |
| 모델 적용 | 로그인한 세션에서 원고를 처리하는 실제 생성 |

파일이 제자리에 놓였는지, 도구가 그 파일을 찾아 쓰는지, 실제로 원고를 어떻게 고치는지는 단계마다 결과를 기록한다.

## 이번 실행의 아홉 조합

Linux와 Python 3.12.14에서 세 CLI의 설치 명령을 실행했다. 새 설치 후 한글과 공백이 있는 경로에서 백업 없이 교체하고, 원본과 설치 파일의 일치와 보조 도구 실행을 확인했다. 빌드와 문서 검사도 통과했다. 단위 테스트 76개 중 74개가 통과했고 Windows의 junction과 PowerShell 검사 두 개는 이 환경에서 건너뛰었다.

이번 실행에서는 설치와 보조 도구, CLI 시작과 가능한 범위의 스킬 인식을 확인했다. 로그인한 에이전트에게 링크를 보내 설치를 맡기는 과정과 원고 윤문은 별도 확인 항목이다. 앞선 버전의 실행 범위는 당시 자료에서 볼 수 있다. [0.8.0 공개 CI](https://github.com/jhchoi0309/im-poet/actions/runs/44085122317), [0.8.1 실행 결과](../evals/results/release-0.8.1.json)

## 자동화

[CLI 호환성 워크플로](../.github/workflows/cli-compatibility.yml)는 세 운영체제와 세 CLI를 교차해 아홉 작업을 실행한다. CLI 버전은 Codex 0.166.0, Claude Code 2.1.325, Gemini CLI 0.68.0으로 고정한다. 각 작업은 설치기의 `--host`와 `--project` 명령, 백업 없는 교체, 보조 도구를 직접 실행한다. 가능한 호스트에서는 실제 발견을 확인하고 결과 JSON을 보관한다. Claude의 계정 인증이나 유료 모델 요청은 이 검사 범위 밖이다.

[일반 검증 워크플로](../.github/workflows/validate.yml)는 세 운영체제와 Python 3.10, 3.13의 여섯 조합을 검사한다. Windows의 junction과 네이티브 PowerShell 검사는 해당 환경에서 실행한다. Linux에서 생략된 검사를 통과로 세지 않는다.

커밋을 올리면 push 이벤트로 두 워크플로가 시작된다. 해당 커밋의 Actions에서 운영체제별 결과를 볼 수 있다. [이전 평가 기록](evaluation.md)

## 경로와 정책

설치기는 한글과 공백이 있는 경로, UTF-8 BOM과 CRLF 입력, 같은 이름의 실제 스킬, 링크와 Windows junction, 교체 도중의 복구를 다룬다. 기본 사용자 경로와 프로젝트 범위, 사용자 지정 `CLAUDE_CONFIG_DIR` 및 `GEMINI_CLI_HOME`을 구분한다. Gemini의 같은 범위에서는 기존 `.agents/skills/im-poet`이 우선한다.

Gemini가 신뢰하지 않는 프로젝트의 스킬을 건너뛰는 것은 호스트 정책이다. 검증기는 사용자 신뢰 규칙을 바꾸지 않고 새 격리 사용자 경로에서 목록과 공용 별칭을 확인한다. CLI의 실제 사용자 설정과 조직 정책, 비활성화 항목은 각 호스트에서 확인한다.

GitHub 업데이트, Mac의 로컬 설치, ChatGPT 계정 스킬의 갱신은 각각 별개다. Gemini 앱과 Antigravity의 기존 안내는 유지하지만 이 아홉 CLI 조합의 실측으로 합산하지 않는다.
