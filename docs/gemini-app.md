# Gemini 앱에서 사용하기

Gemini 앱의 Skills와 Gemini CLI의 로컬 스킬은 별개다. 이 저장소는 앱에 가져올 `SKILL.md` 패키지와 대화에서 스킬을 생성할 때 읽을 [단일 지침](../prompts/gemini-app.txt)을 제공한다. 단일 지침은 원본 `SKILL.md`에서 생성하며 로컬 파일 참조에 의존하지 않는다.

## 링크로 생성 요청

Skills 기능을 사용할 수 있고 공개 GitHub 내용을 읽을 수 있는 Gemini 앱에서 저장소 URL과 함께 “이 스킬 설치해줘”라고 요청한다. 설치를 수행하는 Gemini는 다음 절차를 따른다.

1. README에서 스킬명과 목적을 확인한다.
2. `prompts/gemini-app.txt`의 전체 내용을 읽는다. 이 문서나 README를 윤문 지침 대신 저장하지 않는다.
3. 앱이 제공하는 스킬 생성 기능으로 이름·설명과 실제 지침을 저장한다. 사용자가 링크와 설치를 요청한 맥락에서 필요한 생성 절차를 완료하고, 실제로 저장됐다는 결과를 확인한다.
4. 저장 결과를 확인하지 못했으면 설치 완료라고 보고하지 않는다. 공개 URL을 읽을 수 없다면 확인하지 않은 내용을 요약해 스킬을 만들지 말고, 아래 가져오기 파일을 사용하는 방법을 안내한다.

사용자가 참고할 더 명확한 요청 예:

```text
이 GitHub 저장소의 prompts/gemini-app.txt를 읽고, 그 지침으로 스킬을 만들어 내 Skills에 저장해줘.
```

앱의 계정·네트워크·생성 도구에 따라 링크만으로 저장까지 가능한지는 달라질 수 있다. 링크는 앱의 권한을 우회하거나 생성 기능을 강제로 활성화하지 않는다. 앱에서 실제 생성 요청을 실행한 결과는 이번 개발 환경에서 검증하지 않았다.

## 파일·폴더 가져오기

공통 배포 패키지의 `gemini-app/im-novelist/`와 `gemini-app/im-poet/`는 앱 업로드용 폴더다. 각 폴더의 루트에 `SKILL.md`가 있고, 참고 파일과 외부 통신 없는 바이트 계산 도구만 포함한다. 설치·업로드 스크립트, Git 이력, 바이너리 파일은 포함하지 않는다.

Gemini 앱에서 Customize → Skills → Create → Upload를 열어 원하는 폴더를 선택한다. 원본 `SKILL.md` 파일만 올릴 수도 있지만 참고 문서도 사용하려면 폴더째 가져온다. 내용을 검토한 뒤 앱의 Create 단계까지 완료해야 저장된다. 로컬 `~/.gemini/skills`에 복사한 것만으로 앱 계정에 스킬이 생기는 것은 아니다.

공식 도움말은 스킬 생성·사용을 Gemini 모바일 앱, Mac 앱, 웹 앱에서 지원한다고 설명한다. Windows·Linux에서는 해당 계정으로 웹 앱을 사용할 수 있다. 기능을 사용할 계정은 도움말의 연령·로그인·활동 저장 조건을 충족해야 한다. 일부 계정의 제공 시점이나 조직 설정은 다를 수 있으므로 실제 앱에서 Skills 제공 여부를 확인한다.

## Skills가 제공되지 않는 경우

Gems가 있는 계정에서는 새 Gem의 Instructions에 `prompts/gemini-app.txt` 전문을 넣고 저장할 수 있다. 파일을 Knowledge에만 올리는 것과 지침을 저장하는 것은 구분한다. 전용 스킬·Gem 저장 기능이 없는 환경에서도 새 대화의 첫 메시지에 단일 지침을 붙여 넣고 다음 메시지에 원고를 보낼 수 있다. 이 방식은 해당 대화에서 지침을 적용하는 것이며 영구 설치로 보고하지 않는다.
