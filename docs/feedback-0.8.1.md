# 여섯 편의 윤문에서 0.8.1로

2026년 11월 18일에 제공된 평가에서는 독서, 여행, 사진, 연애, 겨울, 인공지능 에세이 6편을 0.8.0 지침으로 다뤘다. 원문과 당시 윤문에는 각각 73개 본문 문단이 있었고, 윤문 뒤 글자 수는 원문의 약 72~76%였다. 문단 수와 길이는 작업의 범위를 돌아볼 단서다. 뜻을 모두 살렸는지, 글이 더 좋아졌는지는 원문과 결과를 읽어 판단해야 한다.

평가에는 윤문을 작성한 쪽의 재검토가 담겨 있다. 비슷한 요청으로 만든 시험 원고를 사용했으며, 독립 독자나 동일 조건의 대조군은 없었다. 당시 초안에서 가능성을 실제 경험처럼 바꾸었다가 최종 윤문에서 고친 일은, 확실성을 지키라는 기존 규칙에 구체적인 대조 절차가 필요함을 보여 준다.

| 관찰한 문제 | 0.8.1의 적용 | 다시 확인할 질문 |
| --- | --- | --- |
| 문단을 모두 다뤄도 문단 안의 사례와 반론은 빠질 수 있음 | 긴 글은 구간별 독립 의미를 기록한 뒤 결과에 연결하고, 연결되지 않은 요소를 복구 | 원래 있던 조건, 예시와 반론을 결과의 어느 구절에서 읽을 수 있는가 |
| 가능성과 당위가 익숙한 말끝에 묻힘 | 주체와 범위, 조건을 포함해 주장과 어미를 양방향 대조 | 해 볼 수 있다는 말이 늘 그렇게 된다는 말로, 의무가 희망으로 바뀌지 않았는가 |
| 문장이 짧아졌으나 전개는 그대로임 | 원문의 대상과 관계로 대표 구간의 출발점과 도착점을 다시 선택 | 읽는 순서와 여운이 어디에서 달라졌는가 |
| 끝맺음과 비유가 글마다 비슷함 | 마지막 두 문장과 앞 구절을 이어 읽고, 여러 원고의 도입과 결말을 나란히 비교 | 이 원고에서만 닿을 수 있는 질문이나 판단이 남는가 |
| 서로 다른 글이 같은 서정으로 평평해짐 | 수필은 사물과 생각, 소설은 앎의 범위, 논설은 근거와 반론에 호흡을 맡김 | 요청한 어조와 장르가 살아 있고 새로운 장면을 지어내지 않았는가 |
| 문체 검수와 사실 확인이 섞임 | 원문과의 일치 여부, 외부 사실 확인 여부를 별도로 다룸 | 원문의 주장을 새로 증명하거나 보증한 것처럼 표현하지 않았는가 |

전문 윤문은 문장 수를 보존하라는 지시가 아니다. 글 전체가 맡았던 역할을 새 흐름에서 잃지 않는 일이다. 여러 문장을 한곳에 담아도 되고, 같은 문장을 되풀이하며 감정의 초점을 옮겨 가는 자리라면 반복을 살릴 수 있다. 분량과 구조를 고정해 달라는 요청은 그대로 따른다.

[README 첫 비교표](../README.md#문장이-달라지는-자리)에는 평가에서 고른 실제 원문과 당시 윤문만 사용했다. 첨부 보고서와 에세이 전문은 배포물에 포함하지 않는다. [별도로 만든 사례](../evals/cases.json)의 `V811`부터 `V813`은 이 개발에 사용한 가상 원고다. 첨부 여섯 편이나 그 인접 문단을 독립 시험으로 다시 세지 않는다. 평가 범위와 실제 결과는 [평가 기록](evaluation.md)에서 확인할 수 있다.
