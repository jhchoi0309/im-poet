# 조사와 설계

2026-11-14 확장 조사 목록은 작품 140편과 논문 74편입니다. 작품에는 기존 조사 기록 39편과 게시 페이지의 서지 및 본문 일부를 확인한 101편이 포함됩니다. 논문은 이번에 서지와 초록 일부를 확인한 69편, 기존 기록을 인계한 5편입니다. 140편과 74편을 모두 전문 정독한 것은 아닙니다.

[확장 조사 목록](../references/research-catalog-2026-11-14.json)에 각 자료의 출처와 확인 범위를, [편집 판단](../references/research-2026-11-14.md)에 자료와 적용 사이의 제한을 기록했습니다. 단편소설과 일부 공개 매체에 편중된 비대표 표본입니다. 문학 작품과 논문 전문은 재배포하지 않습니다.

선행 조사에서는 말이 놓인 자리와 그 말이 다음 문장으로 이어지는 방식을 살폈습니다. 기존 범위는 [조사 근거](../references/research.md)와 [작품 39편의 목록](../references/source-catalog.json)에 보존했습니다.

2026-10-29에는 권혁웅(2009), 이정인(2018), 문한별(2015)의 KCI 초록과 서지를 다시 확인했습니다. 말소리와 분절, 반복과 병치, 어휘와 문체의 관계를 참고한 범위는 [단어 선택 지침](../references/word-choice.md)에 적었습니다. 이번 확인은 세 논문의 초록에 한정합니다. 선행 조사에서 기록한 본문 확인 범위와 구별했습니다.

문학적인 어휘를 풍부하게 쓰는 기본값과 가운뎃점 제거는 사용자 피드백에 따라 정했습니다. 저자의 교정을 읽는 구체적인 판단은 [교정 사례](../references/editorial-judgment.md)로 정리했습니다. 논문에서 확인한 관점, 작품을 읽으며 남긴 관찰, 사용자가 원하는 표현과 배포 규칙을 각각 구별합니다.

0.4.0의 전면 재서술 절차와 재검수 기준은 실제 사용 결과에 대한 피드백을 반영해 정했습니다. 선행 논문이 이 개정본의 효과나 개별 문장의 아름다움을 검증한 것으로 소개하지 않습니다.

0.5.0에서는 [im-not-ai](https://github.com/epoko77-ai/im-not-ai)의 공개 README와 Codex 스킬, 테스트 안내에서 진단과 윤문, 검수와 반복 평가를 나누는 운영 방식을 참고했습니다. 이 저장소의 규칙과 예문은 im-poet의 전면 재서술에 맞추어 새로 작성했으며, 다른 프로젝트의 코드나 분류표를 복사하지 않았습니다. 원문의 일부만 고치거나 변경량을 제한하는 기준은 채택하지 않았습니다. 이 구조와 어미 선택은 사용자 피드백에 따른 편집 설계이며, 논문으로 효과가 입증된 규칙은 아닙니다.

0.6.0에서는 저자의 목적과 관점 보존, 서로 다른 윤문 지침의 병행, 의미와 문학성의 분리 평가를 보강했습니다. 자료의 관찰과 편집 설계의 선택을 구분하며, 논문을 0.6.0의 효과 검증으로 소개하지 않습니다. 실제 실행과 미실행 항목은 [평가 기록](evaluation.md)에 둡니다.

## 0.7.0의 공개 프로젝트 비교

2026-11-16에는 사용자가 제시한 일곱 저장소의 README와 핵심 스킬을 읽었다. [채택 범위와 읽은 파일](../references/project-comparison-0.7.0.md)을 남겼으며 외부 원문과 개인 문체 데이터는 배포물로 가져오지 않았다. 새 지침과 도구는 자체 작성했다. 이번 비교는 설계 참고이며 외부 스킬의 실제 실행 비교나 새 논문 조사가 아니다. 작품 140편과 논문 74편은 2026-11-14 목록의 확인 범위를 그대로 유지한다.
