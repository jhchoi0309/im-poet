# 조사와 설계

선행 조사에서는 말이 놓인 자리와 그 말이 다음 문장으로 이어지는 방식을 살폈습니다. 무엇을 살폈고 어디까지 확인했는지는 [조사 근거](../references/research.md)에 모았습니다. [작품 목록](../references/source-catalog.json)에는 39편의 링크와 서지, 관찰 메모를 남겼습니다. 문학 작품의 전문은 재배포하지 않습니다.

2026-10-29에는 권혁웅(2009), 이정인(2018), 문한별(2015)의 KCI 초록과 서지를 다시 확인했습니다. 말소리와 분절, 반복과 병치, 어휘와 문체의 관계를 참고한 범위는 [단어 선택 지침](../references/word-choice.md)에 적었습니다. 이번 확인은 세 논문의 초록에 한정합니다. 선행 조사에서 기록한 본문 확인 범위와 구별했습니다.

문학적인 어휘를 풍부하게 쓰는 기본값과 가운뎃점 제거는 사용자 피드백에 따라 정했습니다. 저자의 교정을 읽는 구체적인 판단은 [교정 사례](../references/editorial-judgment.md)로 정리했습니다. 논문에서 확인한 관점, 작품을 읽으며 남긴 관찰, 사용자가 원하는 표현과 배포 규칙을 각각 구별합니다.

0.4.0의 전면 재서술 절차와 재검수 기준은 실제 사용 결과에 대한 피드백을 반영해 정했습니다. 선행 논문이 이 개정본의 효과나 개별 문장의 아름다움을 검증한 것으로 소개하지 않습니다.

0.5.0에서는 [im-not-ai](https://github.com/epoko77-ai/im-not-ai)의 공개 README와 Codex 스킬, 테스트 안내에서 진단과 윤문, 검수와 반복 평가를 나누는 운영 방식을 참고했습니다. 이 저장소의 규칙과 예문은 im-poet의 전면 재서술에 맞추어 새로 작성했으며, 다른 프로젝트의 코드나 분류표를 복사하지 않았습니다. 원문의 일부만 고치거나 변경량을 제한하는 기준은 채택하지 않았습니다. 이 구조와 어미 선택은 사용자 피드백에 따른 편집 설계이며, 논문으로 효과가 입증된 규칙은 아닙니다.
