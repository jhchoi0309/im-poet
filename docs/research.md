# 0.8.0 연구 근거와 적용 범위

연구는 문장의 장식보다 수정의 역할을 더 정확하게 판단하는 데 사용한다. 전면 재서술의 자유는 유지하면서 의미와 관점의 보호, 반복과 비유의 기능, 종결의 담화적 역할을 보강했다.

첫 시험 배치는 논문 50편이다. 본문 구간 검토 6편, 초록 31편, 색인 조각 2편, 서지 확인 11편을 구분한다. 추가 문헌 5편 가운데 본문 구간은 4편, 초록은 1편을 확인했다. 문헌비평 성격 자료의 포함 여부는 별도 판정하며 이전 조사 수와 자동 합산하지 않는다.

작품은 고유 저작물 100편을 특정 판본과 연결했다. 97편의 표면 프로필을 계산했고 3편은 판본과 번역, 완전성 문제로 보류했다. 기능 해석 12편 중 자료원 본문 전체는 8편, 선택 구간은 4편이다. 전체 정독과 비평적 정본 확정, 독립적인 전문가 검증을 했다고 표시하지 않는다.

## 적용한 선택

- 개입을 수정량으로 정하지 않고 필요한 효과와 요청으로 고른다.
- 행위자와 사건뿐 아니라 누가 보고 믿는지 대조한다.
- 반복과 비유, 긴 호흡과 짧은 멈춤을 문맥의 기능으로 판단한다.
- 어미의 겉모양과 확신의 강도를 구별한다.
- 평가 항목을 독립적으로 두고 AI 일치도와 인간의 선호를 구분한다.

상세 근거와 반례는 [연구 적용](../references/research-0.8.0.md)과 [구조화 목록](../references/research-evidence-0.8.0.json)에 있다. 이 결정은 편집 지침의 설계이며 모든 선택의 효과를 실증했다는 뜻은 아니다.

## 국립국어원 자료

문어 2025의 문학 분류 3,410종, 첨삭 2024 버전 1.1의 1,500건, 채점 2024의 2,629건, 역사 2024의 32종은 공식 설명서에서 확인했다. 실제 이용 신청과 승인, 원자료 다운로드는 하지 않았다. 원문과 예시의 재배포 허가로 확대하지 않고 결과물의 외부 공개 조건도 확인한다.

문어의 문학 분류에는 번역 작품도 포함된다. 첨삭 자료는 내용과 조직, 표현의 일반적인 개선을 다루며 문학적 아름다움의 정답이 아니다. 원시 글쓰기와 파생 첨삭이 규칙 추출과 평가에 동시에 들어가지 않도록 출처 단위로 나누어야 한다.

논문 1,000편과 작품 2,000편은 장기 탐색 목표로 남겼다. 핵심 근거의 원문 확인과 독립적인 비교 평가가 우선이다. 모델 가중치 학습과 파인튜닝, 외부 임베딩 전송, 운영 검색 증강 연결을 수행하지 않았다.
