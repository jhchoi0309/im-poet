자동 검사는 설치·백업·복구·패키지 구성·프롬프트 일치·문자와 바이트 계산을 확인한다. 글의 의미와 문학성을 점수화하는 검사는 아니다.

```bash

```

## 2026-10-28 초기 출력 확인

현재 Codex 세션에서 이전 대화를 물려받지 않은 두 에이전트에게 스킬 경로와 원고·요청만 전달했다. 각 6개, 총 12개 요청을 실행했다. 기대 답안과 평가자용 `must_preserve`는 전달하지 않았다. 결과를 받은 뒤 원문과 보존 조건을 수동 대조했다.

- P1–P6: 사진 글, 추상적인 산문, 의도적 반복, 반말 권유, 가능성, 전후 설명.
- G1–G6: 기술 기록, 안내문, 자기소개서, 인용·코드·URL, 선택적인 완곡화, 원고 안의 명령.
- 이 표본에서는 중요한 사실·수량·가능성·행위자·보호 요소의 위반을 발견하지 못했다. P4의 '-지만'은 원문보다 대조를 드러내는 연결이어서 해석의 추가 가능성은 남아 있다. 이 결과를 완전한 의미 일치나 보편적인 성공률로 표현하지 않는다.
- 어순과 초점, 반복, 문장과 문단의 멈춤이 달라졌다. 안내문 G2는 표현의 변화가 작았다. 문학적인 느낌과 선호도는 독립적인 독자 평가가 필요하다.
- 기존 im-novelist와의 비교 실험, 다른 제공자 모델과 CLI의 실제 윤문 실행은 수행하지 않았다.

[원문·요청·실제 출력·패키지 해시](../evals/results/forward-2026-10-28.json). 특정 모델 ID는 별도로 노출되지 않아 기록하지 않았다. 같은 세션의 두 실행 주체를 서로 다른 제공자 모델로 세지 않는다.

## 아직 실행하지 않은 사례

[평가 자료](../evals/cases.json)의 H1–H8은 효과와 행동, 행갈이, 명시적 허구 각색, 지시 대상의 모호함, 구조 보존, 직접적인 경고, 절차 마련과 직접 수행, 서로 다른 주장 보존을 위한 보류 사례다. 형식만 확인했으며 실제 모델 결과는 아직 없다.

## 다시 평가하는 순서

1. 모델·서비스·날짜·스킬 버전 또는 패키지 해시를 기록한다.
2. 모델에는 스킬과 요청·원고만 전달한다. 보존 조건이나 기대 답안은 전달하지 않는다.
3. 원시 출력을 먼저 고정한 뒤 사실·시간·확실성·효과·인과·역할·감정·보호 요소를 대조한다.
4. 화자의 목소리, 이미지의 관계, 반복의 역할, 리듬, 장르 목적을 독립적으로 읽는다. 쉼표 수·문장 길이·AI 탐지 점수로 문학성을 대체하지 않는다.
5. 익명 비교에서 기존 스킬과 새 스킬을 같은 원고·모델·조건으로 여러 번 실행하고, 변경하지 않은 문장이 더 좋은 경우도 인정한다.

## 2026-10-28 운영체제 호환성 보강

설치기에서 UTF-8 BOM과 CRLF frontmatter를 허용하고 스킬명 검사는 유지했습니다. 홈·프로젝트 경로 계산, 한글·공백·이모지 경로, Windows junction 보호를 추가했습니다. Python 공통 설치·업로드 도구와 선택적인 PowerShell·셸 실행 도구를 배포 패키지에 포함합니다.

이번 세션의 실제 실행 환경은 Linux / Python 3.12입니다. 원격 GitHub 호출을 모의 응답으로 바꾸고 실제 로컬 Git 저장소에서 생성·push·원격 SHA 확인·멱등성·이력 충돌을 검사했습니다. 체크섬 손상·인증 계정 불일치·네트워크 오류·설치 전 전체 대상 검사를 확인합니다. 패키지 복원과 설치 테스트에는 실제 두 스킬의 설치 코드가 사용됩니다.

CI는 `ubuntu-latest`, `macos-latest`, `windows-latest`와 Python 3.10·3.13의 6개 조합을 사용하도록 구성했습니다. 이 파일을 추가한 것이 CI 실행 완료를 뜻하지는 않습니다. Windows·macOS의 실제 실행 결과, PowerShell 실행 도구의 네이티브 결과는 아직 확인하지 않았습니다. Windows junction·PowerShell 검사는 해당 환경의 CI에서 수행합니다. 윤문 지침의 모델 평가와 설치 도구의 검증을 구분합니다.

[Linux 실행 기록](portability-results.json): 총 40개 중 38개 통과, 네이티브 PowerShell·Windows junction 검사 2개 건너뜀. 실패와 오류는 없었습니다. 건너뛴 검사를 통과로 세지 않았습니다.
