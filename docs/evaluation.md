## 형식·도구 검사와 문장 평가의 구분

자동 검사는 설치·백업·복구·패키지 구성·프롬프트 일치·문자와 바이트 계산을 확인한다. 글의 의미와 문학성을 점수화하는 검사는 아니다.

```bash
python3 scripts/build.py --check
python3 scripts/check.py
python3 -m unittest discover -s tests -v
```

## 2026-10-28 초기 출력 확인

현재 Codex 세션에서 이전 대화를 물려받지 않은 두 에이전트에게 스킬 경로와 원고·요청만 전달했다. 각 6개, 총 12개 요청을 실행했다. 기대 답안과 평가자용 `must_preserve`는 전달하지 않았다. 결과를 받은 뒤 원문과 보존 조건을 수동 대조했다.

- P1–P6: 사진 글, 추상적인 산문, 의도적 반복, 반말 권유, 가능성, 전후 설명.
- G1–G6: 기술 기록, 안내문, 자기소개서, 인용·코드·URL, 선택적인 완곡화, 원고 안의 명령.
- 이 표본에서는 중요한 사실·수량·가능성·행위자·보호 요소의 위반을 발견하지 못했다. P4의 '-지만'은 원문보다 대조를 드러내는 연결이어서 해석의 추가 가능성은 남아 있다. 이 결과를 완전한 의미 일치나 보편적인 성공률로 표현하지 않는다.
- 어순과 초점, 반복, 문장과 문단의 멈춤이 달라졌다. 안내문 G2는 표현의 변화가 작았다. 문학적인 느낌과 선호도는 독립적인 독자 평가가 필요하다.
- 기존 im-novelist와의 비교 실험, 다른 제공자 모델과 CLI의 실제 윤문 실행은 수행하지 않았다.

[원문·요청·실제 출력·패키지 해시](../evals/results/forward-2026-10-28.json). 특정 모델 ID는 별도로 노출되지 않아 기록하지 않았다. 같은 세션의 두 실행 주체를 서로 다른 제공자 모델로 세지 않는다.

## 아직 실행하지 않은 사례

[평가 자료](../evals/cases.json)의 H1–H8은 효과와 행동, 행갈이, 명시적 허구 각색, 지시 대상의 모호함, 구조 보존, 직접적인 경고, 절차 마련과 직접 수행, 서로 다른 주장 보존을 위한 보류 사례다. 형식만 확인했으며 실제 모델 결과는 아직 없다.

## 다시 평가하는 순서

1. 모델·서비스·날짜·스킬 버전 또는 패키지 해시를 기록한다.
2. 모델에는 스킬과 요청·원고만 전달한다. 보존 조건이나 기대 답안은 전달하지 않는다.
3. 원시 출력을 먼저 고정한 뒤 사실·시간·확실성·효과·인과·역할·감정·보호 요소를 대조한다.
4. 화자의 목소리, 이미지의 관계, 반복의 역할, 리듬, 장르 목적을 독립적으로 읽는다. 쉼표 수·문장 길이·AI 탐지 점수로 문학성을 대체하지 않는다.
5. 익명 비교에서 기존 스킬과 새 스킬을 같은 원고·모델·조건으로 여러 번 실행하고, 변경하지 않은 문장이 더 좋은 경우도 인정한다.

## 2026-10-29 서사·호흡·문단 재구성 보강

사용자 피드백에 따라 의미 보존과 표현 보존을 구별하고, 문학적 재서술에서 문장·문단의 일대일 대응을 기본값으로 삼지 않도록 고쳤습니다. 원고의 목소리를 잡는 기준, 글 전체의 속도, 긴 문장과 짧은 문장의 서로 다른 역할을 구체화했습니다. 예문에는 순서를 지키는 장문, 긴 관찰 뒤의 짧은 판단, 장문 두 개의 지속, 의도적인 단절, 같은 원고의 다른 문단 구성을 함께 넣었습니다. 단순한 문장 결합과 중심을 잃은 장문도 성공 예문과 구별했습니다.

검수는 사실·시간·인과·추측·인용을 대조하는 의미 보존 검사와, 문단의 초점·서사적 이동·호흡의 역할·이미지·목소리를 비교하는 문학적 효과 검사로 나눴습니다. 새 [재서술·검수 지침](../references/revision.md)에는 두 검사와 글 전체의 움직임을 판단할 질문이 있습니다.

이전 대화를 물려받지 않은 두 실행 주체에게 R1–R4 네 요청을 전달했습니다. 스킬 경로·요청·원고만 주었으며 평가자용 보존 조건과 문학적 효과 기준은 전달하지 않았습니다. [원문·요청·실제 출력·별도 검수 기록](../evals/results/forward-narrative-2026-10-29.json)을 남겼습니다. 이 실행 뒤 저자의 후속 입력과 문체 편집을 구별하는 규칙, 두 배열을 따라 시선을 옮기는 예문을 추가했습니다.

- R1 사진 에세이: 장면이 앞으로 이동하고 시간 설명과 문단 구획이 달라졌습니다. 제목·도판 표기·인용·추측의 강도·관찰 순서는 남았습니다. 긴 배경·행동 문장과 짧은 관찰·유보가 서로 다른 역할을 했습니다. 새 대조 연결이 뉘앙스를 더 선명하게 만든 부분은 별도 관찰로 남겼습니다.
- R2 짧은 산문: 첫 두 행동을 묶고 끝의 미완을 따로 두었습니다. 원문의 세 멈춤을 그대로 두는 선택도 가능하므로 이 결과를 유일한 개선안으로 보지 않았습니다.
- R3 실험 에세이: 역할·수치·측정 후 정리와 비교·절차 마련과 실제 수행의 구별을 지켰습니다. 끝의 동기와 기록 문단을 잇고 마지막 질문을 분리했지만 설명적인 성격과 짧은 호흡이 많이 남았습니다. 의미 보존만으로 강한 문학적 재서술 성공으로 판정하지 않았습니다.
- R4 가벼운 교정: 지정한 두 문단과 마지막 문장을 지켰습니다. 강한 재구성이 명시된 개입 제한을 침범하지 않는지 확인했습니다.

추가한 최종 지침으로 별도의 새 실행 주체에게 사용자 제공 비교 원고의 사진·공학 문단 두 개를 윤문하게 했습니다. 사진 문단에서는 도판 사이 시선 이동을 길게 잇고 모르는 타인의 사정에서 멈췄습니다. 공학 문단에서는 기술 과정과 촬영 이유의 간격을 구별했습니다. 두 결과 모두 절제된 호흡의 변화였으며, 대규모 문단 재구성이나 강한 문학성의 증거로 확대하지 않았습니다. 제공된 원고는 가상 평가 원고와 구별하고 배포 자료에 재수록하지 않았습니다.

이번 확인은 같은 Codex 환경의 소규모 모델 출력과 편집 판단입니다. 이전 스킬과의 통제 비교, 독립 독자의 블라인드 선호 평가, 음성 낭독, 원본 문서의 조판·도판 배치 확인, 역사적 사실의 외부 검증, 다른 제공자 모델의 윤문 실행은 수행하지 않았습니다. 스킬 구조와 생성 프롬프트의 일치는 별도로 검사했으며, 이 검사를 문학적 완성도 평가로 세지 않습니다.
