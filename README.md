# im-poet

**문학적인 어휘와 아름다운 서술로 한국어 원고를 다시 쓰는 스킬입니다.**

편지에 적힌 잘 지내라는 말을 거듭 읽을 때, 마음은 그 짧은 안부에 오래 머물기도 합니다. 쓰고 지운 고백에는 전하지 못한 마음이 남습니다. im-poet은 원고에 담긴 감정과 생각을 어울리는 말로 불러내어, 뜻과 문체를 지키면서도 표현은 한층 풍성하게 펼칩니다.

긴 문장은 사물과 기억을 따라 천천히 흐르고, 짧은 문장은 그 끝에서 숨을 고릅니다. 그리움이 머무는 자리와 시선이 옮겨 가는 길을 살피며 어휘를 고르고, 비유를 잇고, 문단의 물결을 다듬습니다. 글쓴이가 건네려던 마음이 독자에게 닿을 수 있도록 말의 결을 가다듬는 일입니다.

에세이와 편지에서는 감정의 여운을, 소설에서는 장면의 흐름을, 보고서와 기술 설명에서는 생각이 이어지는 질서를 살립니다. 문학적인 재서술을 요청하면 문장과 문단을 넓게 다시 구성하고, 담백함을 원하면 표현의 밀도를 낮춥니다. 시로 바꿔 달라는 요청이 있을 때에는 행과 연의 호흡까지 다룹니다. 새로운 사건과 경험을 창작하려면 각색의 범위를 함께 알려 주세요.

## 글에 더하는 것

같은 그리움도 문장마다 다른 모습으로 머뭅니다. 누군가는 보고 싶다고 곧바로 말하고, 누군가는 거듭 읽는 편지 곁에 그 마음을 놓아둡니다. 원고가 품은 정서에 맞춰 고유어와 선명한 동사를 고르고, 사물과 마음 사이에 이어지는 비유를 찾아 서술을 풍성하게 만듭니다.

문장의 길이에도 맡길 일이 있습니다. 함께 보낸 하루를 긴 호흡으로 따라가다가, 끝내 말하지 못한 고백 앞에서 짧게 멈출 수 있습니다. 전면 재서술에서는 문단을 합치거나 나누고 정보가 드러나는 순서를 바꾸어, 글 전체가 저마다 다른 속도로 흐르게 합니다.

글쓴이의 문체와 어조도 함께 살핍니다. 존댓말과 독백, 질문과 망설임 속에서 원고만의 결을 찾고, 지원서의 경험과 판단이나 안내문의 행동 요건처럼 글이 끝까지 전해야 할 내용을 지킵니다. 감정의 주인과 강도, 실제 사건의 순서도 함께 대조합니다.

마지막에는 원문과 수정문을 나란히 읽습니다. 먼저 사실과 뜻을 확인한 뒤, 어휘가 한층 깊어졌는지와 비유가 어우러지는지, 문단을 지나는 호흡에 높낮이가 생겼는지를 따로 살핍니다. 원고에 없는 날씨와 추억, 타인의 마음을 덧붙이지 않으면서도 아름답게 쓸 수 있는 길을 찾습니다.

## 이렇게 다듬습니다

아래 편지에는 그리움이 머물고, 고백에는 보내지 못한 말이 남습니다. 사랑을 다루는 서로 다른 호흡을 보여 주려고 새로 쓴 예문입니다. 같은 원고라도 원하는 분위기와 사용하는 모델에 따라 다른 문장이 나올 수 있습니다.

### 편지 곁에 남은 그리움

원문:

> 네 편지에는 잘 지내라는 말이 적혀 있었다. 나는 그 말을 여러 번 읽었다. 네가 그리웠다. 답장은 아직 쓰지 못했다.

윤문:

> 네 편지에 적힌 잘 지내라는 말을 거듭 읽었다. 그리움은 네게 머물렀고, 답장은 아직 쓰지 못했다.

거듭 읽는 행동에서 마음으로 이어지도록 서술을 바꾸었습니다. 그리움의 대상과 쓰지 못한 답장은 그대로 남습니다.

### 고백을 가르는 짧은 멈춤

원문:

> 사랑한다는 말을 썼다가 곧 지웠고, 아직 네게 보내지 못했다.

윤문:

> 사랑한다고 썼다. 이내 지웠다. 고백은 아직 네게 보내지 못했다.

길게 이어졌던 문장을 나누고 어휘도 골라, 쓰기와 지우기 사이에 멈춤을 두었습니다. 마지막에는 보내지 못한 고백이 남습니다.

### 함께 살던 집을 떠나는 마음

원문:

> 우리가 헤어진 뒤에도 나는 함께 살던 집이 그리웠다. 그 집에서 너와 보낸 날들이 자주 생각났다. 지금도 네가 보고 싶다.

윤문:

> 함께 살던 집은 헤어진 뒤에도 그리움의 자리로 남았다. 너와 보낸 날들이 기억 속에서 자주 되살아나고, 지금도 나는 네가 보고 싶다.

집과 기억을 따라 그리움이 이어지도록 비유와 서술을 골랐습니다. 원문에 있는 마음을 바탕으로 문장을 새로 펼쳤습니다.

[전후 예문](references/examples.md)에는 사랑하는 사람과 하루를 나누는 긴 호흡과, 두 편지 사이를 오가는 서로 다른 문단 구성도 담았습니다. 길어진 문장이 중심을 잃은 경우까지 함께 읽으며 표현과 호흡을 비교할 수 있습니다.

## 바로 쓰기

[독립 프롬프트](prompts/im-poet.md) 전문을 첫 메시지에 붙여 넣은 뒤, 다음 메시지로 원고를 보내세요. 스킬 폴더를 읽지 못하는 대화창에도 이 순서로 핵심 지침을 전달할 수 있습니다. 이런 환경에서는 URL만 건네기보다 프롬프트 전체를 사용하세요.

```text
아래 글을 im-poet으로 문학적이고 시적인 산문으로 다듬어줘.
원문의 뜻과 문체를 살리고, 수정한 글만 보여줘.

[원고]
```

다음처럼 조절할 수도 있습니다.

```text
문학적인 어휘와 아름다운 서술을 풍부하게 써줘.
원고의 정서에 어울리는 비유와 문장의 호흡을 살려줘.
```

```text
문학적이고 서사적으로 전면 윤문해줘.
긴 문장과 짧은 문장을 오가며 호흡의 높낮이를 만들어줘.
사실, 논지, 인용은 지키고, 문장과 문단 구성은 바꿔도 돼.
담백하게 쓰되 짧은 문장 위주로 만들지는 마.
```

```text
권유와 의견은 덜 단정적인 말투로 다듬어줘.
일반적인 효과도 가능성으로 표현해도 돼.
실제 사건, 수치, 일정, 필수 조건은 그대로 유지해줘.
```

```text
이 산문을 짧은 시로 바꿔줘. 새 경험이나 장면은 만들지 마.
```

일반적인 효과를 가능성으로 낮추면 원문의 주장 강도도 달라집니다. 그런 선택은 별도의 요청에 따르며, 시적으로 다듬는다는 이유로 모든 내용을 덜 확실하게 만들지는 않습니다. 변경 이유와 전후 비교는 요청한 경우에만 보여줍니다.

## Windows ,  macOS ,  Linux

Python 3.10 이상에서 동일한 설치기를 사용합니다. macOS, Linux에서는 `python3`, Windows PowerShell에서는 `py -3`로 실행하세요. Windows에서도 설치, 업로드 도구를 Python으로 직접 실행할 수 있습니다.

```powershell
# Windows: 이 저장소 폴더에서 실행
py -3 scripts/install.py --target codex --update
```

```bash
# macOS ,  Linux: 이 저장소 폴더에서 실행
python3 scripts/install.py --target codex --update
```

`codex` 대신 `claude`, `gemini`, `antigravity`(App, IDE), `antigravity-cli`를 선택할 수 있습니다. 패키지의 공통 `install.py`는 두 스킬을 함께 설치하고, `upload.py`는 GitHub 업로드를 처리합니다. 전체 소스와 번들이 함께 제공되므로 설치만 할 때 Git이나 GitHub CLI는 필요하지 않습니다. 자세한 운영체제별 명령은 [공통 패키지 안내](docs/package-usage.md)를 참고하세요.

LF/CRLF와 UTF-8 BOM, 한글, 공백 경로를 처리하고 설치 대상의 심볼릭 링크, Windows junction은 교체하지 않습니다. 현재 직접 실행한 환경은 Linux이며, Windows, macOS 검사는 함께 제공하는 CI에서 실행하도록 구성했습니다. [검증 범위](docs/evaluation.md)를 확인하세요.

## 설치

Python 3.10 이상이 필요합니다. 설치기는 네트워크를 사용하지 않고, 선택한 도구의 스킬 경로로 필요한 파일만 복사합니다. API 키는 필요하지 않습니다.

```bash
git clone https://github.com/jhchoi0309/im-poet.git
cd im-poet

# 사용할 도구에 해당하는 명령을 실행하세요.
python3 scripts/install.py --target claude
python3 scripts/install.py --target gemini
python3 scripts/install.py --target codex
```

| 도구 | 기본 사용자 설치 경로 |
| --- | --- |
| Claude Code | `~/.claude/skills/im-poet/` |
| Gemini CLI | `~/.gemini/skills/im-poet/` |
| Codex | `~/.agents/skills/im-poet/` |
| Antigravity App, IDE | `~/.gemini/config/skills/im-poet/` |
| Antigravity CLI | `~/.gemini/antigravity-cli/skills/im-poet/` |

프로젝트에만 설치하려면 `--project /path/to/project`, 미리 확인하려면 `--dry-run`을 추가하세요. 다른 내용의 기존 설치본은 덮어쓰지 않습니다. 업데이트하려면 `--update`를 사용하며 이전 폴더 전체를 백업합니다. 다른 스킬이나 심볼릭 링크는 교체하지 않습니다.

```bash
python3 scripts/install.py --target codex --dry-run
python3 scripts/install.py --target codex --update
```

ChatGPT 개인 스킬 설치와 각 컴퓨터의 도구별 설치본은 별개입니다. 서비스별 사용 방식은 [호환성 안내](docs/compatibility.md)를 참고하세요.

## 문학 자료에서 가져온 기준

출발점은 공개된 문학 작품을 살핀 선행 조사입니다. 2000~2022년 중심 자료 37편에 2023년 비교 자료 2편을 더한 총 39편으로, 시, 지하철 시, 수필, 단편소설을 포함합니다. 관련 논문 6편은 본문, 표 1편, 본문 일부 1편, 초록 4편으로 읽은 범위를 구분했습니다.

선행 조사에서 살핀 화자의 거리, 구체적인 사물, 이미지의 연결, 반복과 멈춤을 편집 지침으로 옮겼습니다. 구절을 모아 재생하는 방식은 택하지 않았습니다. 이 표본이 한국 문학 전체를 대표하지는 않으며, 2022년 이전이라는 구분도 개별 작품의 AI 사용 여부를 인증하는 기준은 아닙니다.

- [조사 근거와 논문 6편](references/research.md)
- [작품 39편의 원문 링크, 서지, 관찰 메모](references/source-catalog.json)

문학 자료에서 살핀 표현과 구성 방식을 윤문 지침으로 옮겼습니다. 모델 학습이나 파인튜닝은 수행하지 않았으며, 패키지에는 원문 링크와 서지, 자체 관찰을 담았습니다. 공개 작품의 전문과 이미지, 논문 PDF의 저작권은 각 권리자에게 있습니다.

## 구조와 검증

현재 개정본은 **0.3.0**입니다. `VERSION.json`에는 개정 번호와 지침 파일의 SHA-256 지문을 담았습니다. 같은 이름으로 설치된 파일이 여러 곳에 있다면 이 값을 대조해 어떤 본을 읽고 있는지 확인할 수 있습니다.

ChatGPT에 연결한 개인 스킬과 컴퓨터의 설치본은 각각 갱신합니다. 새 패키지에서 설치기를 실행한 뒤 실제 설치 경로의 `VERSION.json`을 확인하세요. 사용한 원고와 스킬의 개정본을 함께 기록하면 이전 원고나 구버전의 결과를 섞어 평가하는 일을 줄일 수 있습니다.
