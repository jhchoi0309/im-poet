# im-poet

**한국어 원고의 뜻과 사실을 살리면서 문장과 문단을 다시 쓰는 윤문 스킬입니다.**

수필에서는 어떤 장면부터 보여 줄지 고르고, 안내문에서는 할 일과 기한이 바로 읽히게 다듬습니다. 원래 말투와 구조를 살리고 싶다면 가벼운 교정을 요청할 수 있습니다.

## 설치 없이 써 보기

아래 지침의 본문을 새 ChatGPT 대화에 붙여 넣으세요. 다음 메시지에 원고와 원하는 수정 범위를 보내면 됩니다. [붙여 넣기용 지침](prompts/im-poet.md)

```text
아래 글을 문학적으로 윤문해 줘. 원문에 있는 사실과 내 말투는 살려 줘.

[원고]
```

Codex, Claude Code, Gemini CLI에서 계속 사용하려면 저장소의 설치 안내를 따르세요. [CLI에 설치하기](#cli에-설치하기)

## 문장이 달라지는 자리

가상의 원고 두 편에 0.8.2.1의 윤문 지침을 적용한 예시입니다.

### 사진을 고르는 수필

**원문**

> 지난겨울 같은 골목을 사흘 연달아 찍었다. 세 번째 날에는 가게 문이 닫혀 있었고, 유리문에 맞은편 간판 불빛이 비쳤다. 나중에 사진을 고르다가 그날 찍은 한 장을 오래 봤다. 왜 그날만 자꾸 생각나는지는 아직 모르겠다.

**윤문**

> 맞은편 간판 불빛이 닫힌 가게의 유리문에 비쳤다. 지난겨울, 같은 골목을 사흘 내리 찍던 마지막 날이었다. 나중에 사진을 고르다가 그날 찍은 한 장을 오래 들여다봤다. 그날만 자꾸 떠오른다. 까닭은 아직 모르겠다.

유리문에 비친 불빛부터 보여 줍니다. 사진을 오래 바라본 뒤에도 화자는 그날만 떠오르는 까닭을 알지 못합니다.

### 시범 운영에 대한 글

**원문**

> 시범 운영을 주 1회에서 2회로 늘리자는 의견이 나왔다. 더 많은 학생에게 참여 기회를 줄 수 있다는 이유였다. 지금 인력으로 감당할 수 있을지는 아직 확인하지 않았다. 확대 여부를 결정하기 전에 운영 인력의 업무량을 확인해야 한다.

**윤문**

> 시범 운영을 확대할지는 운영 인력의 업무량을 확인한 뒤 결정해야 한다. 더 많은 학생이 참여할 수 있다며 주 1회를 2회로 늘리자는 의견이 나왔다. 지금 인력으로 주 2회 운영이 가능한지는 아직 확인 전이다.

결정에 앞서 확인할 사항을 첫 문장에 놓았습니다. 제안의 이유와 주당 횟수, 인력에 관한 불확실성도 남겼습니다.

## 원고는 어디서 처리하나요?

**원고는 평소 쓰는 AI 서비스에서 처리합니다.** 대화 기록과 보관, 모델 개선 설정은 그 서비스의 계정 정책을 따릅니다. [ChatGPT 데이터 제어](https://help.openai.com/en/articles/7730893-data-controls-in-chatgpt)

설치기는 스킬 파일을 로컬에 복사합니다. 선택형 보조 도구 세 개는 지정한 파일을 읽어 금지 문자, 바이트 수, 문장 길이 등을 확인합니다. 설치기와 보조 도구에 원고를 수집해 제작자에게 보내는 기능은 없으며, 별도 가입이나 API 키가 필요하지 않습니다. [설치기](scripts/install_for_agent.py), [문자 검사](scripts/check_output.py), [바이트 계산](scripts/count_text.py), [전후 비교](scripts/review_rewrite.py)

## CLI에 설치하기

Codex, Claude Code 또는 Gemini CLI에 다음 메시지를 보내세요.

```text
https://github.com/jhchoi0309/im-poet
이 스킬을 지금 쓰는 도구에 설치해 줘.
```

직접 설치하려면 Git과 Python 3.10 이상을 사용합니다.

```bash
git clone https://github.com/jhchoi0309/im-poet.git
cd im-poet
python3 scripts/install_for_agent.py --host codex
```

Claude Code는 `--host claude`, Gemini CLI는 `--host gemini`를 지정합니다. Windows, 프로젝트별 설치, 백업 없는 갱신은 설치 안내에 있습니다. [설치 안내](docs/agent-install.md), [Gemini 앱](docs/gemini-app.md), [호환성과 확인 범위](docs/compatibility.md)

## 어떤 연구를 참고했나요?

문장이 달라져도 원문의 주장과 조건이 남았는지 따로 확인합니다. 이 기준은 텍스트 문체 변환 연구에서 가져왔습니다. 한국어 문체론과 수필 연구는 반복과 말끝이 글 안에서 어떤 일을 하는지 보는 데 참고했습니다.

논문 50편과 후속 문헌 5편은 본문 구간, 초록, 색인 조각, 서지 가운데 어디까지 확인했는지 남겼습니다. 작품 100편의 판본을 확인했고, 그중 12편은 반복과 화자의 시선, 끝맺음을 읽어 메모했습니다. [대표 문헌과 적용 기준](docs/research.md), [평가 기록](docs/evaluation.md)
