# im-poet

## 링크만 주고 설치 요청하기

파일을 설치할 수 있는 **Codex·Claude Code·Gemini CLI·Antigravity** 대화에 다음 한 줄을 보내세요.

```text
https://github.com/jhchoi0309/im-poet 이 스킬 설치해줘.
```

세 CLI(Codex·Claude Code·Gemini CLI)와 Antigravity가 현재 도구에 맞는 경로에 이 스킬을 설치하도록 [에이전트 설치 안내](docs/agent-install.md)를 제공합니다. 기본은 사용자 범위이며, “이 프로젝트에만 설치해줘”라고 하면 프로젝트 범위로 설치합니다. 기존 설치본은 백업하고 실제 설치 파일을 확인하도록 했습니다.

**Gemini 앱에서도 사용:** 앱의 Skills 생성 기능에 연결하는 [앱용 안내](docs/gemini-app.md)와 [단일 지침](prompts/gemini-app.txt)을 제공합니다. 앱에서는 계정 스킬을 생성하고, CLI에서는 컴퓨터의 스킬 폴더에 설치합니다. 링크 내용을 읽고 Skills를 생성할 수 있는 앱에서는 같은 설치 요청으로 진행하도록 안내했습니다. 직접 가져올 수 있는 앱용 폴더도 배포 패키지에 포함합니다.

**설치를 수행하는 에이전트에게:** `docs/agent-install.md`를 읽고 설치·검증을 완료하세요. `SKILL.md`만 읽고 설치가 끝났다고 보고하지 마세요. Python이 있으면 제공된 설치기를, 없으면 안내된 파일 복사 절차를 사용하세요. 호스트의 파일 접근·권한 정책을 따르세요.


**원문의 뜻과 목소리를 지키며, 한국어 글을 문학적이고 서사적인 산문으로 다듬는 윤문 스킬입니다.**

무엇을 오래 바라볼지, 같은 말이 돌아올 때 무엇이 달라지는지, 어디에서 문장을 멈출지 살핍니다. 사물의 관계와 말의 리듬을 다루어 에세이·사진 글부터 메시지·자기소개서·안내문·보고서·기술 설명까지 문학적인 산문으로 다듬습니다.

긴 문장으로 관찰·행동·생각을 이어 가고 짧은 문장으로 초점과 멈춤을 만들어 호흡의 높낮이를 살립니다. 담백함을 단문 위주로 쓰는 것으로 해석하지 않습니다. 문학적 재서술에서는 사실과 논지를 고정한 채 문장 경계·문단 구획·정보 제시 순서를 재구성합니다. 원문과 수정문을 한 문장씩 대응시키는 방식에 머물지 않습니다.

시로 바꿔 달라는 요청이 없으면 원래 산문 형식을 유지합니다. 새 장면을 창작하려면 각색이나 허구 창작을 별도로 요청하면 됩니다.

## 글에 더하는 것

- **사물을 바라보는 초점.** 원문에 있는 사진·컵·회로·서류도 문장의 중심이 될 수 있습니다. 감상을 꾸미기보다 무엇을 보고 있는지 선명하게 합니다.
- **이어지는 이미지.** 문장마다 다른 비유를 붙이기보다 중심 사물과 다른 장면이 어떻게 연결되는지 살핍니다.
- **긴 호흡과 짧은 멈춤.** 장문에는 지속·누적·시선의 이동을, 단문에는 초점·판단·단절을 맡깁니다. 문단마다 같은 장단 배열을 반복하지 않고 글 전체의 속도와 밀도를 다룹니다.
- **문단 단위의 서사.** 원고에 있는 행동과 생각이 움직이는 길을 찾습니다. 전면 재서술에서는 문단을 합치거나 나눌 수 있으며, 새 장면이나 감정으로 서사를 만들지는 않습니다.
- **말하듯 쓰는 목소리.** 존댓말·독백·질문·망설임도 문학적 표현으로 다룹니다. 권유에는 선택의 여지를 남길 수 있고, 모든 어미를 같은 형태로 맞추지 않습니다.
- **장르에 맞는 밀도.** 에세이에서는 여운을, 지원서에서는 경험과 판단을, 안내문에서는 정확한 행동 요건을 살립니다. 분명한 한 문장을 그대로 남기는 것도 퇴고입니다.
- **두 차례 검수.** 먼저 사실·시제·인과·추측·인용을 대조하고, 별도로 문단의 초점·서사·장단 호흡·이미지·목소리를 비교합니다. 의미 보존 검사 통과나 수정 문단 수를 문학적 완성도의 증거로 삼지 않습니다.

## 이렇게 다듬습니다

아래 예시는 설명을 위해 만든 가상 원고입니다. 기존 문학 작품을 옮긴 문장이 아니며 실제 출력은 원고·요청·모델에 따라 달라집니다.

| 글 | 원문 | 가능한 윤문 |
| --- | --- | --- |
| 행동의 순서 | 인화지를 봉투에서 꺼냈습니다. 한 장씩 책상 위에 펼쳤습니다. 그런 다음 같은 길을 찍은 두 장을 나란히 놓았습니다. | 봉투에서 꺼낸 인화지를 한 장씩 책상 위에 펼친 다음, 같은 길을 찍은 두 장을 나란히 놓았습니다. |
| 관찰과 판단 | 사진 왼쪽에는 정류장이 있었습니다. 오른쪽에는 셔터가 내려진 가게가 있었습니다. 둘 사이에는 나무 한 그루가 서 있었습니다. 저는 어느 쪽을 사진의 중심으로 삼을지 정하지 못했습니다. | 사진 왼쪽에는 정류장이, 오른쪽에는 셔터가 내려진 가게가 있었고, 그 사이에 나무 한 그루가 서 있었습니다. 어느 쪽을 사진의 중심으로 삼을지는 정하지 못했습니다. |
| 추상적인 산문 | 나는 선택을 미루었고 그 이유를 아직 설명하지 못한다. | 나는 선택을 미뤘다. 왜 미뤘는지는 아직 설명하지 못한다. |
| 자기소개서 | 팀이 개선안을 만들었습니다. 저는 측정 기록을 정리했습니다. | 개선안은 팀이 만들었습니다. 저는 측정 기록을 정리했습니다. |
| 권유 | 경복궁 한번 가봐. | 경복궁에 한번 가보는 건 어떨까? |
| 안내문 | 신청은 11월 3일 18시에 마감합니다. | 11월 3일 18시, 신청을 마감합니다. |

문장 나누기나 쉼표 추가가 유일한 방법은 아닙니다. 원문의 날씨·빛·냄새·몸짓·기억을 새로 만들지 않고도 초점과 호흡을 바꿀 수 있습니다. 기술 용어와 수치도 문학성을 위해 뭉개지 않습니다.

[전후 예문](references/examples.md)에는 긴 문장 둘이 이어지는 경우, 짧은 문장들이 단절을 만드는 경우, 같은 원고의 서로 다른 문단 구성, 합쳤지만 중심을 잃은 문장을 함께 담았습니다. 문장 합치기 자체를 문학적 효과로 평가하지 않습니다.

## im-novelist와 고르기

| 스킬 | 중심 작업 |
| --- | --- |
| [im-novelist](https://github.com/jhchoi0309/im-novelist) | 기존 im-poetry의 기능을 이어받아 AI식 상투어·번역투·불분명한 연결을 자연스럽게 정리 |
| im-poet | 의미 보존을 바탕으로 시선·이미지·리듬·반복·말의 거리를 적극적으로 다루는 문학적 윤문 |

두 스킬을 함께 설치해 두고 원하는 이름을 지정할 수 있습니다. `im-poet`은 모든 글을 운문으로 만드는 스킬이나 특정 작가를 복제하는 도구가 아닙니다.

## 바로 쓰기

[독립 프롬프트](prompts/im-poet.md) 전체를 첫 메시지에 붙여 넣고 다음 메시지로 원고를 보내세요. 스킬 폴더를 읽지 못하는 대화창에서도 핵심 지침을 전달할 수 있습니다. URL만 전달하는 방식보다 프롬프트 전문을 사용하세요.

```text
아래 글을 im-poet으로 문학적이고 시적인 산문으로 다듬어줘.
사실과 화자의 목소리는 유지하고, 수정한 글만 보여줘.

[원고]
```

다음처럼 조절할 수도 있습니다.

```text
비유는 절제하고 문장의 호흡과 반복을 살려줘.
```

```text
문학적이고 서사적으로 전면 윤문해줘.
긴 문장과 짧은 문장을 오가며 호흡의 높낮이를 만들어줘.
사실·논지·인용은 지키고, 문장과 문단 구성은 바꿔도 돼.
담백하게 쓰되 짧은 문장 위주로 만들지는 마.
```

```text
권유와 의견은 덜 단정적인 말투로 다듬어줘.
일반적인 효과도 가능성으로 표현해도 돼.
실제 사건·수치·일정·필수 조건은 그대로 유지해줘.
```

```text
이 산문을 짧은 시로 바꿔줘. 새 경험이나 장면은 만들지 마.
```

일반적 효과를 가능성으로 낮추는 것은 원문의 주장 강도를 바꾸는 선택입니다. 시적으로 다듬으라는 요청만으로 모든 내용을 덜 확실하게 바꾸지는 않습니다. 변경 이유와 전후 비교는 요청한 경우에만 보여줍니다.

## Windows · macOS · Linux

Python 3.10 이상에서 동일한 설치기를 사용합니다. macOS·Linux에서는 `python3`, Windows PowerShell에서는 `py -3`로 실행하세요. Windows에서도 설치·업로드 도구를 Python으로 직접 실행할 수 있습니다.

```powershell
# Windows: 이 저장소 폴더에서 실행
py -3 scripts/install.py --target codex --update
```

```bash
# macOS · Linux: 이 저장소 폴더에서 실행
python3 scripts/install.py --target codex --update
```

`codex` 대신 `claude`, `gemini`, `antigravity`(App·IDE), `antigravity-cli`를 선택할 수 있습니다. 패키지의 공통 `install.py`는 두 스킬을 함께 설치하고, `upload.py`는 GitHub 업로드를 처리합니다. 전체 소스와 번들이 함께 제공되므로 설치만 할 때 Git이나 GitHub CLI는 필요하지 않습니다. 자세한 운영체제별 명령은 [공통 패키지 안내](docs/package-usage.md)를 참고하세요.

LF/CRLF와 UTF-8 BOM, 한글·공백 경로를 처리하고 설치 대상의 심볼릭 링크·Windows junction은 교체하지 않습니다. 현재 직접 실행한 환경은 Linux이며, Windows·macOS 검사는 함께 제공하는 CI에서 실행하도록 구성했습니다. [검증 범위](docs/evaluation.md)를 확인하세요.

## 설치

Python 3.10 이상이 필요합니다. 설치기는 네트워크를 사용하지 않고, 선택한 도구의 스킬 경로로 필요한 파일만 복사합니다. API 키는 필요하지 않습니다.

```bash
git clone https://github.com/jhchoi0309/im-poet.git
cd im-poet

# 사용할 도구에 해당하는 명령을 실행하세요.
python3 scripts/install.py --target claude
python3 scripts/install.py --target gemini
python3 scripts/install.py --target codex
```

| 도구 | 기본 사용자 설치 경로 |
| --- | --- |
| Claude Code | `~/.claude/skills/im-poet/` |
| Gemini CLI | `~/.gemini/skills/im-poet/` |
| Codex | `~/.agents/skills/im-poet/` |
| Antigravity App·IDE | `~/.gemini/config/skills/im-poet/` |
| Antigravity CLI | `~/.gemini/antigravity-cli/skills/im-poet/` |

프로젝트에만 설치하려면 `--project /path/to/project`, 미리 확인하려면 `--dry-run`을 추가하세요. 다른 내용의 기존 설치본은 덮어쓰지 않습니다. 업데이트하려면 `--update`를 사용하며 이전 폴더 전체를 백업합니다. 다른 스킬이나 심볼릭 링크는 교체하지 않습니다.

```bash
python3 scripts/install.py --target codex --dry-run
python3 scripts/install.py --target codex --update
```

ChatGPT 개인 스킬 설치와 각 컴퓨터의 도구별 설치본은 별개입니다. 서비스별 사용 방식은 [호환성 안내](docs/compatibility.md)를 참고하세요.

## 문학 자료에서 가져온 기준

2000~2022년 중심 자료 37편과 2023년 비교 자료 2편, 총 39편의 공개 작품을 살핀 선행 조사를 바탕으로 만들었습니다. 시·지하철 시·수필·단편소설을 포함합니다. 관련 논문 6편은 본문·표 1편, 본문 일부 1편, 초록 4편의 확인 범위를 구분했습니다.

작품의 구절을 모아 재생하는 대신, 화자의 거리·구체적 사물·이미지의 연결·반복과 멈춤을 편집 지침으로 옮겼습니다. 표본 조사이며 한국 문학 전체를 대표하지 않습니다. 2022년 이전이라는 기준은 개별 작품의 AI 사용 여부를 인증하지 않습니다.

- [조사 근거와 논문 6편](references/research.md)
- [작품 39편의 원문 링크·서지·관찰 메모](references/source-catalog.json)

이 자료로 모델을 학습하거나 파인튜닝한 것은 아닙니다. 공개된 작품의 전문·이미지·논문 PDF를 패키지에 재배포하지 않습니다.
