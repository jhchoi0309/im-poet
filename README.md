# im-poet

**뜻을 지키며, 한국어 원고를 문학적이고 아름다운 산문으로 다시 씁니다.**

익숙한 문장에도 아직 드러나지 않은 풍경과 생각의 결이 있습니다. im-poet은 원고가 바라보는 대상을 따라가며 말과 말 사이의 거리를 고릅니다. 오래 머물 시선은 긴 호흡으로 잇고, 짧은 문장에는 멈춤과 전환을 맡깁니다. 문단이 흘러가는 속도도 함께 살핍니다.

기본은 문학적 전면 재서술입니다. 원문의 뜻과 사실을 지키면서 문장과 문단, 정보가 드러나는 순서까지 새롭게 구성할 수 있습니다. 아름다운 어휘와 비유를 넉넉히 고르되, 글에 이미 있는 감정과 사유를 선명하게 하는 표현을 찾습니다. 원고가 충분히 말한 자리에서는 한 구절을 덜어 낼 수도 있습니다.

현재 버전은 **0.8.0**입니다. 연구 자료를 바탕으로 수정의 기능과 반례, 관점과 종결, 의미와 문학적 효과의 검수를 보강했습니다. 근거를 읽은 일과 실제 윤문 품질을 검증한 일은 구별합니다. 문학성이나 사람의 글과의 구별 불가능성을 보장하지 않습니다.

## 문장이 달라지는 자리

아래는 편집의 선택을 보여 주려고 새로 쓴 가상 원고입니다. 특정 문학 작품에서 가져온 구절이나 성능 실험의 결과가 아닙니다.

| 선택 | 원문 | 가능한 윤문 |
| --- | --- | --- |
| 긴 호흡의 지속 | 그가 떠난 뒤에도 나는 일요일마다 두 사람 몫의 차를 끓였다. 두 잔 가운데 한 잔은 마시지 않았다. 그 습관은 겨울 내내 이어졌다. | 그가 떠난 뒤에도 일요일이면 나는 두 사람 몫의 차를 끓였고, 두 잔 가운데 한 잔은 마시지 않은 채 겨울을 보냈다. |
| 짧은 멈춤 | 그 사람에게 쓰던 편지는 세 번 고쳐 썼지만 보내지 않았다. | 세 번 고쳐 쓴 편지. 그 사람에게 보내지는 않았다. |
| 시선의 흐름 | 도서관에서 한 시간을 기다리는 동안 창밖으로 사람들이 지나가는 모습을 보았다. 그 사람들이 어디로 가는지는 몰랐다. | 도서관에서 한 시간을 기다리며 창밖을 지나는 사람들을 바라보았다. 저 사람들은 어디로 가는 걸까. 알 수 없었다. |
| 개념을 펼치기 | 목적지에 빨리 도착하려고 걸으면 길은 지나가는 공간이 된다. 산책에서는 걷는 과정에 의미를 둔다. | 도착을 서두르는 걸음 앞에서 길은 지나가야 할 공간이 된다. 산책은 그 길을 지나는 과정에 마음을 둔다. |

긴 문장을 만든 사실만으로 문학적인 변화가 생기지는 않습니다. 짧은 멈춤도 문장부호를 늘리는 데 그치면 힘을 잃습니다. 원문과 새 문단을 나란히 읽으며 시선과 생각이 실제로 움직이는지 살핍니다. 사실의 순서와 감정의 크기, 인물의 짐작과 전언도 함께 대조합니다.

## 사용할 때

다음 요청과 원고를 함께 전달하면 됩니다.

```text
im-poet을 적용해 문학적이고 아름답게 전면 재서술해 주세요.
뜻과 사실은 유지하고 문장과 문단은 자유롭게 바꿔 주세요.
긴 호흡과 짧은 멈춤을 글의 흐름에 맞게 고르고, 어미도 다양하게 써 주세요.
```

원문 표현을 유지하고 싶다면 가벼운 윤문을, 특정 문체를 참고하려면 직접 쓴 샘플을 함께 지정할 수 있습니다. 에세이와 소설, 서간과 비평, 지원서와 기술 설명에서 글의 목적에 맞는 개입을 고릅니다. 편지만을 위한 스킬은 아닙니다. 시를 요청하지 않으면 산문으로 씁니다.

사실과 수치, 인용과 지정 표현은 보호합니다. 문학적 재서술의 기본 범위에 없는 사건과 경험, 타인의 마음을 만들지 않습니다. 어미를 다양하게 고르는 동안에도 원문의 가능성과 확실성을 지킵니다. 출력 전체에서 가운뎃점을 제거하며, 정확한 인용과 문자 금지가 충돌하면 그 충돌을 숨기지 않습니다.

## 링크로 설치 요청하기

Codex, Claude Code 또는 Gemini CLI에 아래 링크와 요청을 전달하세요.

```text
https://github.com/jhchoi0309/im-poet
이 스킬을 지금 사용하는 도구에 설치해 주세요.
```

설치 담당 에이전트는 [설치 안내](docs/agent-install.md)를 읽고 현재 도구 하나에 설치합니다. 기본은 사용자 범위입니다. 새 설치와 업데이트를 구별하고 원본 지문과 복사된 파일을 대조합니다. 실제 CLI가 발견하고 사용하는지는 별도로 확인합니다.

| 도구 | 사용자 기본 경로 | 프로젝트 경로 |
| --- | --- | --- |
| Codex CLI | `~/.agents/skills/im-poet` | `.agents/skills/im-poet` |
| Claude Code | `~/.claude/skills/im-poet` | `.claude/skills/im-poet` |
| Gemini CLI | `~/.gemini/skills/im-poet` 또는 기존 공용 경로 | `.gemini/skills/im-poet` 또는 기존 공용 경로 |

Gemini는 같은 범위의 `.agents/skills`를 먼저 읽습니다. 설치기는 그곳에 im-poet이 있으면 해당 경로를 갱신합니다. Claude의 사용자 지정 설정 경로는 `CLAUDE_CONFIG_DIR`를, Gemini의 사용자 홈은 `GEMINI_CLI_HOME` 설정을 따릅니다. Windows에서는 실제 사용자 프로필, WSL에서는 WSL의 홈을 사용합니다.

## 직접 설치하거나 백업 없이 업데이트하기

Git과 Python 3.10 이상이 있다면 새 소스 폴더에서 실행합니다. 아래 host는 현재 사용하는 도구 하나를 고르는 선택지입니다.

```bash
git clone https://github.com/jhchoi0309/im-poet.git
cd im-poet
python3 scripts/install_for_agent.py --host codex
# Claude Code: --host claude
# Gemini CLI: --host gemini
```

```powershell
git clone https://github.com/jhchoi0309/im-poet.git
Set-Location im-poet
py -3 scripts/install_for_agent.py --host codex
```

기존 설치본을 백업 없이 갱신하도록 선택했다면 다음 명령을 사용합니다. 해당 im-poet 폴더 안의 파일을 새 패키지로 교체합니다.

```bash
python3 scripts/install_for_agent.py --host codex --no-backup
```

다른 도구는 host 값만 바꿉니다. Python이 없어도 핵심 윤문 지침은 작동하며, 에이전트는 설치 안내에 적힌 전체 파일 복사 절차를 사용할 수 있습니다. Gemini 앱의 계정 설치는 [앱 안내](docs/gemini-app.md)로 구분합니다. Antigravity의 기존 설치 경로도 [호환성 문서](docs/compatibility.md)에 남겼습니다.

## 아홉 조합의 지원과 확인

Windows, macOS, Linux와 세 CLI를 조합한 아홉 경로를 대상으로 설치, 백업 없는 갱신, 파일 지문과 보조 도구를 확인하도록 자동화했습니다. [CLI 호환성 워크플로](.github/workflows/cli-compatibility.yml)는 아홉 조합을 독립적으로 실행합니다. 파일 검사와 CLI 발견, 로그인 후 실제 생성은 서로 다른 검증 단계입니다.

현재 릴리스에서 실제로 실행한 환경과 결과, 미확인 항목은 [호환성](docs/compatibility.md)과 [평가 기록](docs/evaluation.md)에 기록합니다. 자동화 파일이 있다는 사실만으로 모든 네이티브 환경의 통과를 선언하지 않습니다.

## 연구와 검수

수정의 양보다 원고에 필요한 일을 판단합니다. 문체를 보존하는 요청과 전면 재서술을 구분하고, 반복과 비유, 어미의 기능을 문맥에서 읽습니다. 의미와 문학적 효과는 따로 검수합니다. 문장 길이와 어휘 다양성은 다시 읽을 위치를 알려 주는 단서입니다.

첫 시험 배치의 논문 50편과 추가 문헌 5편은 확인 범위가 서로 다릅니다. 작품 100편은 판본을 식별했고, 그중 12편에 기능 해석 메모를 작성했습니다. 1천 편과 2천 편의 분석을 마쳤거나 모델을 학습했다고 표현하지 않습니다. 국립국어원 자료는 설명서 네 종을 확인했으며 승인 대상 원자료를 내려받지 않았습니다.

- [연구 개요](docs/research.md)와 [0.8.0 연구 적용](references/research-0.8.0.md)
- [수정의 조건과 반례](references/revision-decisions.md)와 [검수 기준](references/quality-review.md)
- [변경 기록](CHANGELOG.md)과 [배포 패키지 사용법](docs/package-usage.md)

```bash
python3 scripts/check.py

```
