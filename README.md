# im-poet

**원문의 뜻과 글쓴이의 목소리를 지키며, 한국어 글을 문학적이고 서사적인 산문으로 다듬는 윤문 스킬입니다.**

원고에 있는 사물과 행동을 따라가며 무엇을 오래 바라볼지, 같은 말이 돌아올 때 무엇이 달라지는지 살핍니다. 관찰과 생각이 이어지는 곳에서는 문장을 길게 잇고, 초점이 모이는 자리에서는 짧게 멈춥니다. 글 전체에 호흡의 높낮이를 만드는 일입니다.

에세이와 사진 글, 메시지와 자기소개서, 안내문과 보고서, 기술 설명까지 각 글의 목적에 맞춰 다듬습니다. 문학적으로 다시 쓰는 경우에는 사실과 논지를 남긴 채 문장 경계·문단 구획·정보를 보여 주는 순서를 재구성할 수 있습니다. 원문 한 문장에 수정문 하나를 맞출 필요는 없습니다.

담백한 문장도 길게 흐를 수 있습니다. 감정과 수식은 절제하되, 관찰이 이어질 시간까지 줄이지는 않습니다. 시로 바꿔 달라는 요청이 없으면 산문을 유지하며, 새로운 장면을 창작하려면 각색이나 허구 창작을 별도로 요청하면 됩니다.

## 링크만 주고 설치 요청하기

파일을 설치할 수 있는 **Codex·Claude Code·Gemini CLI·Antigravity** 대화에 다음 한 줄을 보내세요.

```text
https://github.com/jhchoi0309/im-poet 이 스킬 설치해줘.
```

링크를 받은 Codex·Claude Code·Gemini CLI와 Antigravity는 [에이전트 설치 안내](docs/agent-install.md)를 따라 현재 도구에 맞는 경로를 선택하도록 구성했습니다. 기본은 사용자 범위입니다. “이 프로젝트에만 설치해줘”라고 하면 그 프로젝트에 설치하고, 기존 설치본이 있으면 백업한 뒤 실제 파일을 확인하도록 했습니다.

**Gemini 앱에서도 사용:** [앱용 안내](docs/gemini-app.md)와 [단일 지침](prompts/gemini-app.txt)은 앱의 Skills 생성 기능으로 이어집니다. 링크 내용을 읽고 Skills를 생성할 수 있는 앱에서는 같은 요청으로 계정 스킬을 만들도록 안내했으며, 직접 가져올 수 있는 앱용 폴더도 배포 패키지에 담았습니다. CLI에서는 컴퓨터의 스킬 폴더에 설치합니다. 계정에 저장하는 일과 로컬 파일을 복사하는 일은 각각 확인해야 합니다.

**설치를 수행하는 에이전트에게:** `docs/agent-install.md`를 읽고 설치·검증을 완료하세요. `SKILL.md`만 읽고 설치가 끝났다고 보고하지 마세요. Python이 있으면 제공된 설치기를, 없으면 안내된 파일 복사 절차를 사용하세요. 호스트의 파일 접근·권한 정책을 따르세요.
## 글에 더하는 것

편지와 컵, 회로와 서류도 문장의 중심이 될 수 있습니다. 원문에 있는 대상을 먼저 보고, 그 대상이 다시 나타날 때 다른 장면과 어떤 관계를 맺는지 살핍니다. 그 사이로 행동과 생각이 움직일 길을 찾습니다.

긴 문장은 지속과 누적, 시선의 이동을 맡고 짧은 문장은 초점과 판단, 때로는 단절을 맡습니다. 전면 재서술에서는 문단을 합치거나 나누며 글 전체의 속도와 밀도를 다루되, 문단마다 같은 장단 배열을 되풀이하지 않습니다. 서사를 위해 새 장면이나 감정을 보태지도 않습니다.

존댓말과 독백, 질문과 망설임에도 글쓴이의 목소리가 있습니다. 권유에는 선택의 여지를 남길 수 있고, 문장 끝을 모두 같은 형태로 맞추지 않아도 됩니다. 에세이의 여운, 지원서의 경험과 판단, 안내문의 정확한 행동 요건을 각각 살핍니다. 이미 분명한 한 문장을 남겨 두는 것도 퇴고입니다.

수정이 끝나면 두 번 대조합니다. 먼저 사실·시제·인과·추측·인용을 살피고, 이어 문단의 초점과 서사, 장단의 호흡과 이미지, 글쓴이의 목소리를 따로 읽습니다. 의미를 지켰다는 확인이나 많이 고쳤다는 수치만으로 문학적 완성도를 판단하지 않습니다.

## 이렇게 다듬습니다

아래 예문은 사랑을 다루는 편지와 고백, 기다림과 이별을 바탕으로 만든 가상 원고입니다. 기존 문학 작품에서 가져온 문장은 아닙니다. 실제 결과는 원고·요청·모델에 따라 달라집니다.

| 글 | 원문 | 가능한 윤문 |
| --- | --- | --- |
| 편지와 고백 | 나는 아직 너를 사랑한다. 네가 쓴 편지를 책상 위에 펼쳤다. 첫 문장부터 마지막 문장까지 천천히 읽었다. 그런 다음 편지를 접었다. 아직 답장은 쓰지 못했다. | 책상 위에 펼친 네 편지를 첫 문장부터 마지막 문장까지 천천히 읽고 나서 접었다. 나는 아직 너를 사랑한다. 답장은 아직 쓰지 못했다. |
| 관찰과 마음 | 너는 오늘 회사에서 만난 사람들의 이름과 점심에 먹은 메뉴를 이야기했다. 나는 맞은편에 앉아 그 말을 듣고 있었다. 나는 네가 좋았다. | 네가 오늘 회사에서 만난 사람들의 이름을 말하고 점심에 먹은 메뉴를 이야기하는 동안, 나는 맞은편에 앉아 그 말을 듣고 있었다. 나는 네가 좋았다. |
| 짧은 멈춤 | 사랑한다는 말을 썼다. 지웠다. 아직 보내지는 못했다. | 사랑한다는 말을 썼다. 지웠다. 아직 보내지는 못했다. |
| 모르는 마음 | 네 답장을 읽었다. 답장은 짧았다. 너는 화가 난 것 같았다. 정말 그런지는 묻지 않았다. | 짧은 네 답장을 읽었다. 네가 화가 난 것 같았지만, 정말 그런지는 묻지 않았다. |

문장을 나누거나 잇고, 어순과 초점을 옮기는 동안 원문이 말한 사실은 남아 있어야 합니다. 날씨·빛·냄새·몸짓·기억을 새로 만들지 않고도 호흡은 달라질 수 있습니다. 기술 용어와 수치 역시 그 정확함을 지킵니다.

[전후 예문](references/examples.md)에서는 사랑하는 사람과 하루를 나누는 긴 호흡, 고백을 썼다 지우는 짧은 멈춤, 헤어지기 전후의 편지를 읽는 서로 다른 문단 구성을 비교합니다. 합쳤지만 중심을 잃은 문장도 함께 담았습니다. 문장이 길어졌다는 사실과 그 길이가 하는 일은 따로 판단합니다.

## im-novelist와 고르기

| 스킬 | 중심 작업 |
| --- | --- |
| [im-novelist](https://github.com/jhchoi0309/im-novelist) | 기존 im-poetry의 기능을 이어받아 AI식 상투어·번역투·불분명한 연결을 자연스럽게 정리 |
| im-poet | 의미 보존을 바탕으로 시선·이미지·리듬·반복·말의 거리를 적극적으로 다루는 문학적 윤문 |

두 스킬을 함께 설치해 두고 작업에 맞는 이름을 지정할 수 있습니다. `im-poet`은 원래 글의 장르를 따르며, 모든 글을 운문으로 바꾸거나 특정 작가의 문장을 복제하지 않습니다.

## 바로 쓰기

[독립 프롬프트](prompts/im-poet.md) 전문을 첫 메시지에 붙여 넣은 뒤, 다음 메시지로 원고를 보내세요. 스킬 폴더를 읽지 못하는 대화창에도 이 순서로 핵심 지침을 전달할 수 있습니다. 이런 환경에서는 URL만 건네기보다 프롬프트 전체를 사용하세요.

```text
아래 글을 im-poet으로 문학적이고 시적인 산문으로 다듬어줘.
사실과 화자의 목소리는 유지하고, 수정한 글만 보여줘.

[원고]
```

다음처럼 조절할 수도 있습니다.

```text
비유는 절제하고 문장의 호흡과 반복을 살려줘.
```

```text
문학적이고 서사적으로 전면 윤문해줘.
긴 문장과 짧은 문장을 오가며 호흡의 높낮이를 만들어줘.
사실·논지·인용은 지키고, 문장과 문단 구성은 바꿔도 돼.
담백하게 쓰되 짧은 문장 위주로 만들지는 마.
```

```text
권유와 의견은 덜 단정적인 말투로 다듬어줘.
일반적인 효과도 가능성으로 표현해도 돼.
실제 사건·수치·일정·필수 조건은 그대로 유지해줘.
```

```text
이 산문을 짧은 시로 바꿔줘. 새 경험이나 장면은 만들지 마.
```

일반적인 효과를 가능성으로 낮추면 원문의 주장 강도도 달라집니다. 그런 선택은 별도의 요청에 따르며, 시적으로 다듬는다는 이유로 모든 내용을 덜 확실하게 만들지는 않습니다. 변경 이유와 전후 비교는 요청한 경우에만 보여줍니다.

## Windows · macOS · Linux

Python 3.10 이상에서 동일한 설치기를 사용합니다. macOS·Linux에서는 `python3`, Windows PowerShell에서는 `py -3`로 실행하세요. Windows에서도 설치·업로드 도구를 Python으로 직접 실행할 수 있습니다.

```powershell
# Windows: 이 저장소 폴더에서 실행
py -3 scripts/install.py --target codex --update
```

```bash
# macOS · Linux: 이 저장소 폴더에서 실행
python3 scripts/install.py --target codex --update
```

`codex` 대신 `claude`, `gemini`, `antigravity`(App·IDE), `antigravity-cli`를 선택할 수 있습니다. 패키지의 공통 `install.py`는 두 스킬을 함께 설치하고, `upload.py`는 GitHub 업로드를 처리합니다. 전체 소스와 번들이 함께 제공되므로 설치만 할 때 Git이나 GitHub CLI는 필요하지 않습니다. 자세한 운영체제별 명령은 [공통 패키지 안내](docs/package-usage.md)를 참고하세요.

LF/CRLF와 UTF-8 BOM, 한글·공백 경로를 처리하고 설치 대상의 심볼릭 링크·Windows junction은 교체하지 않습니다. 현재 직접 실행한 환경은 Linux이며, Windows·macOS 검사는 함께 제공하는 CI에서 실행하도록 구성했습니다. [검증 범위](docs/evaluation.md)를 확인하세요.

## 설치

Python 3.10 이상이 필요합니다. 설치기는 네트워크를 사용하지 않고, 선택한 도구의 스킬 경로로 필요한 파일만 복사합니다. API 키는 필요하지 않습니다.

```bash
git clone https://github.com/jhchoi0309/im-poet.git
cd im-poet

# 사용할 도구에 해당하는 명령을 실행하세요.
python3 scripts/install.py --target claude
python3 scripts/install.py --target gemini
python3 scripts/install.py --target codex
```

| 도구 | 기본 사용자 설치 경로 |
| --- | --- |
| Claude Code | `~/.claude/skills/im-poet/` |
| Gemini CLI | `~/.gemini/skills/im-poet/` |
| Codex | `~/.agents/skills/im-poet/` |
| Antigravity App·IDE | `~/.gemini/config/skills/im-poet/` |
| Antigravity CLI | `~/.gemini/antigravity-cli/skills/im-poet/` |

프로젝트에만 설치하려면 `--project /path/to/project`, 미리 확인하려면 `--dry-run`을 추가하세요. 다른 내용의 기존 설치본은 덮어쓰지 않습니다. 업데이트하려면 `--update`를 사용하며 이전 폴더 전체를 백업합니다. 다른 스킬이나 심볼릭 링크는 교체하지 않습니다.

```bash
python3 scripts/install.py --target codex --dry-run
python3 scripts/install.py --target codex --update
```

ChatGPT 개인 스킬 설치와 각 컴퓨터의 도구별 설치본은 별개입니다. 서비스별 사용 방식은 [호환성 안내](docs/compatibility.md)를 참고하세요.

## 문학 자료에서 가져온 기준

출발점은 공개된 문학 작품을 살핀 선행 조사입니다. 2000~2022년 중심 자료 37편에 2023년 비교 자료 2편을 더한 총 39편으로, 시·지하철 시·수필·단편소설을 포함합니다. 관련 논문 6편은 본문·표 1편, 본문 일부 1편, 초록 4편으로 읽은 범위를 구분했습니다.

선행 조사에서 살핀 화자의 거리, 구체적인 사물, 이미지의 연결, 반복과 멈춤을 편집 지침으로 옮겼습니다. 구절을 모아 재생하는 방식은 택하지 않았습니다. 이 표본이 한국 문학 전체를 대표하지는 않으며, 2022년 이전이라는 구분도 개별 작품의 AI 사용 여부를 인증하는 기준은 아닙니다.

- [조사 근거와 논문 6편](references/research.md)
- [작품 39편의 원문 링크·서지·관찰 메모](references/source-catalog.json)

이 자료로 모델을 학습하거나 파인튜닝한 것은 아닙니다. 공개된 작품의 전문·이미지·논문 PDF를 패키지에 재배포하지 않습니다.
