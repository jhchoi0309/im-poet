# im-poet

**원문의 뜻과 문체를 살리며, 한국어 글을 문학적이고 서사적인 산문으로 다듬습니다.**

글은 눈앞의 풍경에서 시작되기도 하고, 지나온 시간을 더듬으며 생각으로 이어지기도 합니다. im-poet은 원고에 담긴 장면과 생각을 따라가며, 그 뜻에 어울리는 아름다운 말과 서술을 찾습니다.

문학적인 어휘를 넉넉히 고르고 사물과 생각을 잇는 비유를 살핍니다. 긴 문장은 기억과 시선을 따라 천천히 흐르고, 짧은 문장은 말이 닿은 자리에서 잠시 멈춥니다. 문단을 지나는 속도에도 변화를 주어, 글이 처음 품었던 마음이 더 선명하게 드러나도록 합니다.

에세이와 편지에서는 감정이 머무는 시간을, 소설에서는 장면이 이어지는 흐름을 살립니다. 지원서와 보고서, 기술 설명에서도 글의 목적에 맞는 표현과 호흡을 찾습니다. 사실과 논지, 인용은 지키면서 문장과 문단을 새롭게 구성할 수 있습니다. 기본 윤문에서는 원고에 없는 사건이나 감정을 더하지 않습니다.

## 이렇게 다듬습니다

풍경과 기억, 일상과 배움처럼 서로 다른 글을 떠올리며 새로 쓴 예문입니다. 같은 원고도 요청과 사용하는 모델에 따라 다른 문장으로 피어날 수 있습니다.

| 글의 장면 | 원문 | 가능한 윤문 |
| --- | --- | --- |
| 풍경을 바라보는 시간 | 해가 지자 강물의 색이 점점 짙어졌다. 나는 다리 위에서 그 모습을 한동안 바라봤다. | 해가 저물자 강물의 빛깔이 서서히 깊어졌고, 나는 다리 위에서 그 모습을 한동안 바라보았다. |
| 지나온 집을 떠올릴 때 | 오래 살던 집을 떠난 뒤에도 그곳에서 보낸 시간이 가끔 생각났다. 지금은 그곳에 살지 않는다. | 오래 살던 집을 떠난 뒤에도 그곳에서 보낸 시간은 가끔 기억으로 돌아왔다. 이제 나는 그곳에 살지 않는다. |
| 일상 속의 걸음 | 낙엽이 쌓인 길을 걸었다. 발밑에서 낙엽이 바스락거렸다. 한참 걸은 뒤 공원에 도착했다. | 낙엽이 쌓인 길을 걸었다. 발밑의 바스락거림과 함께 한참을 걸어 공원에 닿았다. |
| 말없이 함께 걷는 길 | 친구와 함께 먼 길을 걸었다. 걷는 동안 우리는 말이 거의 없었다. 나는 그 시간이 편안했다. | 친구와 먼 길을 함께 걸었다. 말이 드문 그 시간은 내게 편안했다. |
| 배움에서 만난 질문 | 한 문제를 여러 번 풀었다. 같은 곳에서 계속 틀렸다. 그제야 내가 무엇을 모르는지 알게 되었다. | 한 문제를 몇 번이고 풀면서도 같은 자리에서 거듭 틀렸다. 그제야 내가 무엇을 모르는지 알았다. |
| 소식을 기다리는 짧은 멈춤 | 나는 오래 망설이다 편지를 보냈고, 답장은 아직 오지 않았다. | 오래 망설이다 편지를 보냈다. 답장은 아직 오지 않았다. |
| 숫자가 남은 기록 | 전압을 세 번 측정했다. 값은 1.2 V, 1.3 V, 1.2 V였다. 평균은 약 1.23 V였다. | 전압을 세 차례 측정한 값은 1.2 V, 1.3 V, 1.2 V였다. 그 평균은 약 1.23 V였다. |

풍경의 변화는 긴 호흡으로 따라가고, 편지를 보낸 뒤에는 아직 오지 않은 답장 앞에서 짧게 멈춥니다. 뜻과 시간, 수치가 바뀌지 않도록 살피면서 원고에 어울리는 표현을 고른 예시입니다.

[전후 예문](references/examples.md)에는 긴 문장과 짧은 멈춤을 비교하는 사례, 같은 원고를 다른 문단으로 구성한 사례, 의미가 달라지는 실패 예시가 더 있습니다.

## 글을 다듬는 자리에서

같은 단어라도 글마다 놓인 자리가 다릅니다. im-poet은 원고의 좋은 문장에서 어미와 어휘, 감정을 드러내는 밀도와 생각이 이어지는 순서를 살핍니다. 존댓말과 전문용어를 지키면서도 문학적인 문장을 쓸 수 있습니다.

전면 재서술을 요청하면 어순과 문장 경계를 바꾸고 문단을 합치거나 나누어, 정보가 드러나는 길을 다시 만듭니다. 담백함을 원하면 감정과 수식의 밀도를 낮춥니다. 길고 짧은 문장은 저마다 맡은 일이 있을 때 고릅니다.

수정이 끝나면 두 차례 읽습니다. 먼저 사실과 시간, 인과와 추측, 인용이 원문과 어긋나지 않는지 살핍니다. 이어서 어휘와 비유가 어울리는지, 문단의 움직임과 호흡이 글의 문체를 살리는지 따로 살핍니다. 시를 요청한 경우에는 행과 연의 호흡도 다룹니다.

## 링크로 설치하기

파일을 설치할 수 있는 **Codex, Claude Code, Gemini CLI, Antigravity** 대화에 다음과 같이 요청하세요.

```text
https://github.com/jhchoi0309/im-poet 이 스킬 설치해줘.
```

에이전트가 [설치 안내](docs/agent-install.md)를 읽고 현재 도구에 맞는 경로를 선택하도록 구성했습니다. 기본 설치 범위는 사용자 계정입니다. “이 프로젝트에만 설치해줘”라고 요청하면 프로젝트 경로를 사용하고, 기존 설치본이 있다면 백업한 뒤 파일을 확인합니다.

**Gemini 앱:** [앱용 안내](docs/gemini-app.md)와 [단일 지침](prompts/gemini-app.txt)을 사용해 앱의 Skills에 저장할 수 있습니다. 링크 읽기와 스킬 생성이 가능한 환경이라면 같은 요청으로 진행할 수 있습니다. 직접 가져올 앱용 폴더도 배포 패키지에 담았습니다. 앱 계정에 저장한 스킬과 컴퓨터에 설치한 CLI 스킬은 각각 확인해 주세요.

**설치를 맡은 에이전트에게:** `docs/agent-install.md`를 읽고 현재 도구에 설치한 뒤 실제 파일을 검증하세요. Python이 있으면 제공된 설치기를 사용하고, 없으면 안내된 파일 복사 절차를 따르세요. 호스트의 파일 접근과 권한 정책을 지켜 주세요.

## 바로 사용하기

스킬을 설치했다면 원고와 함께 이렇게 요청할 수 있습니다.

```text
im-poet으로 아래 글을 문학적이고 서사적으로 다듬어줘.
원문의 뜻과 문체를 살리고, 수정한 글만 보여줘.

[원고]
```

원하는 표현과 호흡을 더 구체적으로 알려 주어도 좋습니다.

```text
문학적인 어휘와 아름다운 서술을 풍부하게 써줘.
원고의 정서에 어울리는 비유와 문장의 호흡을 살려줘.
긴 문장과 짧은 문장을 오가며 호흡의 높낮이를 만들어줘.
사실, 논지, 인용은 지키고 문장과 문단 구성은 바꿔도 돼.
```

담백한 문체나 짧은 시를 원한다면 그 뜻을 함께 적어 주세요. 일반적인 효과에 대한 단정을 가능성으로 완화하거나 새로운 장면을 창작하는 일은 별도 요청에 따릅니다. 변경 이유와 전후 비교도 요청한 경우에 보여 줍니다.

스킬 폴더를 읽지 못하는 대화창에서는 [독립 프롬프트](prompts/im-poet.md) 전문을 첫 메시지에 붙여 넣고, 다음 메시지로 원고를 보내세요.

## Windows, macOS, Linux에서 설치하기

Python 3.10 이상이 필요합니다. macOS와 Linux에서는 `python3`, Windows PowerShell에서는 `py -3`로 설치기를 실행하세요.

```powershell
# Windows: 이 저장소 폴더에서 실행
py -3 scripts/install.py --target codex --update
```

```bash
# macOS 또는 Linux: 이 저장소 폴더에서 실행
python3 scripts/install.py --target codex --update
```

`codex` 대신 `claude`, `gemini`, `antigravity` 또는 `antigravity-cli`를 선택할 수 있습니다. 두 스킬을 함께 배포하는 패키지의 설치와 업로드 방법은 [공통 패키지 안내](docs/package-usage.md)에 있습니다.

설치기는 LF와 CRLF, UTF-8 BOM, 한글과 공백이 포함된 경로를 처리합니다. 설치 대상의 심볼릭 링크와 Windows junction은 교체하지 않습니다. 이번에 직접 실행한 환경은 Linux이며, Windows와 macOS 검사는 CI에서 실행하도록 구성했습니다. 실제 확인 범위는 [평가 기록](docs/evaluation.md)에 남겼습니다.

## 직접 설치하기

설치기는 네트워크나 API 키 없이 필요한 파일을 선택한 도구의 스킬 경로로 복사합니다. 저장소를 받은 뒤 사용할 도구에 맞는 명령을 실행하세요.

```bash
git clone https://github.com/jhchoi0309/im-poet.git
cd im-poet

python3 scripts/install.py --target claude
python3 scripts/install.py --target gemini
python3 scripts/install.py --target codex
```

| 도구 | 기본 사용자 설치 경로 |
| --- | --- |
| Claude Code | `~/.claude/skills/im-poet/` |
| Gemini CLI | `~/.gemini/skills/im-poet/` |
| Codex | `~/.agents/skills/im-poet/` |
| Antigravity App, IDE | `~/.gemini/config/skills/im-poet/` |
| Antigravity CLI | `~/.gemini/antigravity-cli/skills/im-poet/` |

프로젝트에만 설치하려면 `--project /path/to/project`를, 미리 확인하려면 `--dry-run`을 추가하세요. 기존 설치본을 갱신할 때에는 `--update`를 사용합니다. 이전 폴더 전체는 백업으로 남습니다.

```bash
python3 scripts/install.py --target codex --dry-run
python3 scripts/install.py --target codex --update
```

ChatGPT 개인 스킬과 컴퓨터의 도구별 설치본은 각각 갱신합니다. 서비스별 사용 방식은 [호환성 안내](docs/compatibility.md)를 참고하세요.

## 문학 자료에서 길어 올린 기준

출발점은 공개 문학 작품을 살핀 선행 조사입니다. 2000년부터 2022년까지의 중심 자료 37편과 2023년 비교 자료 2편, 모두 39편의 시와 지하철 시, 수필, 단편소설을 다루었습니다. 관련 논문 6편은 본문과 표를 확인한 1편, 본문 일부를 읽은 1편, 초록을 확인한 4편으로 범위를 구분했습니다.

그 자료에서 살핀 화자의 거리와 사물, 이어지는 이미지와 반복, 멈춤을 편집 지침으로 옮겼습니다. 관찰을 글쓰기의 선택지로 삼은 것이며, 이 표본을 한국 문학 전체의 대표 분포로 보지는 않습니다. 연도만으로 개별 작품의 AI 사용 여부를 판단할 수도 없습니다.

- [조사 근거와 논문 6편](references/research.md)
- [작품 39편의 원문 링크와 서지, 관찰 메모](references/source-catalog.json)

논문에서 확인한 관점과 편집 과정의 해석, 사용자 피드백으로 정한 규칙은 구별해 기록했습니다. 모델 학습이나 파인튜닝은 수행하지 않았습니다. 패키지에는 원문 링크와 서지, 자체 관찰을 담았으며 작품 전문과 이미지, 논문 PDF는 배포하지 않습니다.
