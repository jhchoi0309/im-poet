# im-poet

**원고의 뜻을 지키면서 한국어 산문의 말과 호흡을 다시 고릅니다.**

눈이 녹는 거리를 한 문장으로 지나갈 수 있습니다. 두 문장으로 나누면 첫 문장 끝에서 눈이 잠시 머뭅니다. im-poet은 원고를 읽으며 어디에 시선을 두고, 어느 말에서 멈출지 살핍니다.

기본은 문학적 전면 재서술입니다. 문장과 문단을 다시 짜고, 독자가 사실을 만나는 순서도 바꿀 수 있습니다. 화자가 본 것과 짐작한 것, 논설이 내세운 근거와 조건은 초안과 원문을 대조해 지킵니다. 원고가 이미 제 말을 한 자리에서는 그대로 두거나 한 구절을 덜어 냅니다.

**0.8.2**에는 원문과 윤문을 나란히 읽을 예시 여덟 쌍을 실었습니다. 문장과 문단을 다듬는 지침을 소개글과 내부 문서에도 적용했습니다. 윤문에 쓰는 자료의 범위와 설치 파일이 하는 일도 공개합니다.

## 문장이 달라지는 자리

2026년 11월 18일에 다룬 시험 에세이 여섯 편에서 원문과 당시 윤문을 그대로 가져왔습니다. 문장을 나누어 시선을 옮긴 곳도 있고, 고쳐 쓴 뒤에도 말의 강도를 그대로 지킨 곳도 있습니다.

| 글과 선택 | 원문 | 윤문 | 달라진 자리 |
| --- | --- | --- | --- |
| 겨울 / 짧은 멈춤 | 그러나 눈의 아름다움은 오래 지속되지 않는다. 시간이 흐르면 눈은 녹아 사라지고, 하얗게 빛나던 거리는 다시 본래의 모습으로 돌아간다. | 눈은 오래 머물지 않는다. 시간이 지나 녹고 나면 하얗게 빛나던 거리는 제 모습으로 돌아간다. | 짧은 첫 문장에 눈이 머물고, 다음 문장에서 거리로 시선이 옮겨 갑니다. |
| 여행 / 회상의 호흡 | 사용했던 물건들을 제자리에 놓고 여행 중 찍었던 사진을 다시 살펴보면 이미 지나간 순간들이 마음속에서 되살아난다. 여행지에서 구입한 작은 물건 하나에도 그날의 날씨와 거리의 소음, 함께했던 사람의 표정이 겹쳐지는 듯하다. | 쓰던 물건을 제자리에 놓고 여행 중 찍은 사진을 다시 보면 지나간 순간이 살아난다. 여행지에서 산 작은 물건에는 그날의 날씨와 거리의 소음, 함께한 사람의 표정이 겹쳐지는 듯하다. | 손에 잡히는 물건에서 날씨와 소음, 표정으로 이어집니다. 그날이 겹쳐 보인다는 인상은 화자의 말끝에 남습니다. |
| 여행 / 두 사람이 보는 풍경 | 우리가 여행지에서 마주하는 것은 단순히 아름다운 배경이 아니라, 누군가에게는 너무나 익숙하고 평범한 하루의 일부다. | 내 눈에는 여행지의 풍경인 곳이 누군가에게는 평범한 하루의 자리다. | 여행자의 눈과 그곳에 사는 사람의 일상이 한 장소에서 만납니다. |
| 인공지능 / 가능성의 강도 | 인공지능은 산업의 생산성을 높이고 새로운 직업과 서비스를 만들어 낼 가능성을 가지고 있다. | 인공지능은 산업의 생산성을 높이고 새로운 직업과 서비스를 만들 가능성이 있다. | ‘가능성이 있다’에 멈춰 전망의 강도를 지킵니다. |
| 독서 / 조건과 반론 | 우리는 종종 독서량을 숫자로 기록하고, 읽은 책의 목록을 성취의 증거처럼 여기곤 한다. 물론 꾸준히 책을 읽는 습관은 의미 있는 노력이다. 하지만 독서가 하나의 경쟁이나 자기계발을 위한 도구로만 남게 된다면, 책이 가진 본래의 깊이를 충분히 경험하기 어려울 수 있다. | 읽은 권수를 기록하고 목록을 성취의 증거로 삼기 쉽다. 꾸준히 읽는 습관은 그 자체로 의미 있는 노력이지만, 독서가 경쟁이나 자기계발의 도구로만 남으면 책의 깊이를 충분히 만나기 어려울 수 있다. | 읽는 습관의 가치를 짚고, 읽기가 경쟁으로 좁아질 때의 문제를 한 호흡에 잇습니다. |
| 사진 / 찍는 사람의 자리 | 카메라가 기록한 이미지는 실제 세계의 일부이지만, 동시에 사진가의 의도와 관점이 반영된 결과이기도 하다. | 카메라에 기록된 것은 실제 세계의 일부이지만, 그 이미지에는 찍는 사람의 의도와 관점도 들어 있다. | ‘찍는 사람’을 드러내고, 한 사진에 실제 풍경과 사진가의 시선이 함께 있다는 뜻을 간결하게 풉니다. |
| 연애 / 배려가 쌓이는 시간 | 이러한 작은 배려들은 겉으로 보기에는 평범하지만, 오랜 시간 쌓이면서 두 사람 사이에 신뢰와 안정감을 만들어 낸다. | 겉으로 평범해 보이는 행동이 오랜 시간 쌓여 두 사람 사이에 신뢰와 안정감을 만든다. | 앞서 나온 안부와 배려를 ‘행동’으로 받아, 그 일이 쌓이는 시간에 무게를 둡니다. |
| 겨울 / 창 너머의 시선 | 창문에는 실내의 온기와 바깥의 냉기가 만나 작은 물방울이 맺히고, 그 물방울 너머로 익숙한 풍경이 조금 흐릿하게 보인다. | 실내의 온기와 바깥의 냉기가 만나는 창문에는 작은 물방울이 맺히고, 그 너머의 익숙한 풍경은 조금 흐려진다. | 온기와 냉기가 만나는 창에서 물방울로, 다시 뿌옇게 흐린 풍경으로 이어집니다. |

여덟 쌍은 모두 0.8.0 때의 작업에서 골랐습니다. 당시에는 서로 다른 글이 비슷한 감상으로 끝나기도 했습니다. 그 결과를 읽고 원문의 내용을 빠짐없이 살피는 방법과 글마다 끝맺음을 고르는 기준을 보강했습니다. [0.8.1에 반영한 평가](docs/feedback-0.8.1.md)

## 사용할 때

다음 요청과 원고를 함께 전달하면 됩니다.

```text
im-poet을 적용해 문학적이고 아름답게 전면 재서술해 주세요.
뜻과 사실은 유지하고 문장과 문단은 자유롭게 바꿔 주세요.
긴 호흡과 짧은 멈춤을 글의 흐름에 맞게 고르고, 어미도 다양하게 써 주세요.
```

말투와 구조를 살리고 싶다면 가벼운 교정을 요청하세요. 닮게 쓰고 싶은 문장이 있다면 직접 쓴 글을 샘플로 지정할 수 있습니다. 같은 윤문이라도 수필에서는 대상에 머무는 호흡을, 기술 설명에서는 수치와 조건이 읽히는 순서를 다룹니다. 시는 따로 요청할 수 있습니다.

전문 윤문에서는 근거와 사례, 조건과 반론이 새 글의 어디에 남았는지 대조합니다. 원문의 가능성은 가능성으로, 서술자의 인상은 인상으로 남깁니다. 외부 사실 확인은 별도로 요청할 수 있습니다. 출력에서 가운뎃점을 덜고, 정확한 인용에 그 문자가 있으면 원문을 보존한 채 직접 인용을 보류합니다.

## 내 글은 어디서 처리되나요?

원고는 평소 쓰는 AI 서비스가 처리합니다. im-poet은 윤문 지침과 참고 문서, 선택형 Python 보조 도구 세 개를 제공합니다. 이 도구들은 지정한 파일의 금지 문자와 바이트 수를 확인하고, 전후 문장의 길이와 어미 분포를 살필 단서를 터미널에 표시합니다. 설치와 보조 도구는 로컬 파일로 작동합니다. 제작자에게 원고와 API 키를 건네거나 별도 서비스에 가입하는 과정은 없습니다. [설치기](scripts/install_for_agent.py), [문자 검사](scripts/check_output.py), [바이트 계산](scripts/count_text.py), [전후 비교](scripts/review_rewrite.py)

윤문 지침은 지정한 원고와 문체 샘플만 작업에 쓰도록 합니다. 파일 저장과 외부 사실 확인은 사용자가 요청한 범위에서 수행합니다. 채팅 기록, 입력 보관과 모델 개선에 관한 설정은 사용하는 AI 서비스와 계정의 데이터 정책을 따릅니다. [ChatGPT 데이터 제어](https://help.openai.com/en/articles/7730893-data-controls-in-chatgpt)

## 링크로 설치 요청하기

Codex, Claude Code 또는 Gemini CLI에 아래 링크와 요청을 전달하세요.

```text
https://github.com/jhchoi0309/im-poet
이 스킬을 지금 사용하는 도구에 설치해 주세요.
```

에이전트는 지금 사용하는 도구의 사용자 폴더를 찾고, 설치한 파일을 원본과 대조합니다. 이어서 도구에서 im-poet을 불러올 수 있는지 확인합니다. [설치 안내](docs/agent-install.md)

| 도구 | 사용자 기본 경로 | 프로젝트 경로 |
| --- | --- | --- |
| Codex CLI | `~/.agents/skills/im-poet` | `.agents/skills/im-poet` |
| Claude Code | `~/.claude/skills/im-poet` | `.claude/skills/im-poet` |
| Gemini CLI | `~/.gemini/skills/im-poet` 또는 기존 공용 경로 | `.gemini/skills/im-poet` 또는 기존 공용 경로 |

Gemini는 같은 범위의 `.agents/skills`를 먼저 읽습니다. 설치기는 그곳에 im-poet이 있으면 해당 경로를 갱신합니다. Claude의 사용자 지정 설정 경로는 `CLAUDE_CONFIG_DIR`를, Gemini의 사용자 홈은 `GEMINI_CLI_HOME` 설정을 따릅니다. Windows에서는 실제 사용자 프로필, WSL에서는 WSL의 홈을 사용합니다.

## 직접 설치하거나 백업 없이 업데이트하기

Git과 Python 3.10 이상으로 설치합니다. `--host`에는 지금 쓸 도구를 지정합니다.

```bash
git clone https://github.com/jhchoi0309/im-poet.git
cd im-poet
python3 scripts/install_for_agent.py --host codex
# Claude Code: --host claude
# Gemini CLI: --host gemini
```

```powershell
git clone https://github.com/jhchoi0309/im-poet.git
Set-Location im-poet
py -3 scripts/install_for_agent.py --host codex
```

백업 없이 갱신하려면 아래 명령을 실행합니다. 해당 im-poet 폴더 안에 직접 추가한 파일도 새 패키지로 교체됩니다.

```bash
python3 scripts/install_for_agent.py --host codex --no-backup
```

다른 도구는 `--host` 값을 바꿉니다. Python 없이도 핵심 지침을 사용할 수 있습니다. 파일 전체를 복사하는 방법과 Gemini 앱 계정에 담는 방법은 각 안내에서 확인하세요. [로컬 설치](docs/agent-install.md), [Gemini 앱](docs/gemini-app.md), [Antigravity 경로](docs/compatibility.md)

## 연구와 검수

문장을 크게 고치면 원래 뜻이 따라왔는지부터 확인해야 합니다. `Evaluating Style Transfer for Text`에서 문체의 변화와 내용 보존을 따로 살피는 기준을 가져왔습니다. `Style over Story`와 `LitBench`를 참고해 겉으로 매끄럽게 읽히는 문장이 이야기의 내용까지 지켰는지, 평가가 글의 길이에 흔들리지 않는지도 살핍니다. [연구 문헌과 반영한 원칙](docs/research.md#대표-문헌과-지침에-반영한-부분)

첫 조사 목록은 논문 50편, 후속 기록은 문헌 5편입니다. 자료마다 본문 구간, 초록, 서지 가운데 어디까지 확인했는지 남겼습니다. 작품 100편은 판본을 식별했고, 12편에서 반복과 관점, 종결이 하는 일을 읽었습니다. 국립국어원 자료는 공식 설명서 네 종을 검토했습니다. 연구 결과는 스킬의 편집 지침과 검수 기준에 반영했습니다. [확인 범위와 원자료 이용 기록](docs/research.md)
