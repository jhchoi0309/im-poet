# 문단 재구성과 두 차례 검수

문학적 재서술이나 전면 윤문을 시작할 때에는, 특히 긴 글일수록 개별 문장을 고치기 전에 본문이 어디로 움직이는지 먼저 읽어라. 아래 방법을 문단마다 같은 모양으로 반복하지 마라. 이 과정은 작업을 위한 것이다. 사용자가 요청하지 않으면 결과만 보여 주어라.

## 목소리를 실제 기준으로 삼기

원고 안에서 이미 잘 쓰인 문장을 골라 다음 특징을 짧게 파악하라.

- 말의 거리: 합쇼체·해요체·독백·직설·질문 중 무엇이 유지되는가.
- 감정의 밀도: 대상을 본 뒤 판단하는가, 감정을 먼저 말하는가. 감정을 얼마나 직접 드러내는가.
- 앎의 범위: 모르는 점·추측·타인의 내면을 어떻게 구별하는가.
- 언어의 재료: 전문용어·구어·구체적 사물·추상적 질문을 어떻게 오가는가.
- 고유한 호흡: 어느 대목을 이어 가고 어디에 멈추는가. 원래 있는 의도적인 거침은 무엇인가.

예를 들어 '절제된 합쇼체, 대상을 본 뒤 질문, 공학 용어 유지, 모르는 부분을 단정하지 않음'이라는 기준을 잡을 수 있다. 이 특성이 없는 원고에 기본 문체로 입히지는 마라. 사용자가 준 특정 문장의 정확한 보존 조건과, 닮아 갈 목소리의 기준 문장을 구별하라.

## 고정한 내용을 다른 경로로 보여 주기

1. 사실·주장·인용·조건·직접 지정된 문장과 구조를 확인하라. 사실의 실제 발생 순서와 독자에게 알리는 순서를 구별하라.
2. 문단마다 출발하는 대상과 도착하는 생각·질문·상태를 잡으라. 사건이 있는 글은 이미 주어진 행동·관찰의 순서를 드러내고, 설명하는 글은 개념과 근거가 이어지는 길을 잡으라.
3. 같은 역할을 하는 문단을 합치거나 하나의 문단에서 시선·논증이 바뀌는 곳을 나누어라. 사건의 순서를 바꿀 때에는 시간 표현으로 실제 순서를 남기고 인과관계를 바꾸지 마라. 절을 옮기는 대규모 개편은 요청 범위를 확인하라.
4. 정보를 먼저 모아 긴 호흡에 실을지, 하나씩 드러내며 멈출지 대표 문단의 다른 안을 비교하라. 같은 사실과 목소리를 유지하는 안끼리 비교하라. 가장 많이 고친 안을 자동 선택하지 마라.
5. 선택한 안을 앞뒤 문단과 붙여 다시 읽어라. 문단 하나의 효과가 글 전체에서는 반복이나 과장이 될 수 있다.

전면 재서술에서는 문단의 구성까지 다루어라. '뜻을 지켜라'를 '문장과 문단을 그대로 지켜라'로 좁혀 읽지 마라. 다만 가볍게 다듬기·문단 고정처럼 명시된 제한은 먼저 지켜라. 문체만 바꾸라는 요청에서도 논증과 사건의 관계를 남긴 채, 제한하지 않은 문장 경계와 호흡은 다룰 수 있다.

전후 원고에 저자의 피드백이 함께 있다면 어떤 사실과 삭제, 표현이 나중에 저자로부터 왔는지 먼저 구별하라. 저자가 새로 확인한 관찰을 편집자가 지어낸 장면으로 보지 마라. 한 원고에서 저자가 지운 문장을 다른 원고의 삭제 규칙으로 옮기지도 마라. 비교표의 '추천' 표시 역시 편집 판단이다. 실제 문장을 나란히 놓고 의미를 다시 보라.

## 글 전체에서 속도를 달리하기

역사적 사실을 따라가던 글이 개인의 경험에 머물고, 반론에 응답한 뒤 앞의 장소로 돌아올 때에는 구간마다 다른 속도가 필요할 수 있다. 원고에 실제로 있는 흐름을 읽어라. 이 구간들을 새로 채워 넣지는 마라.

- 설명에서는 근거와 조건을 따라갈 수 있게 하라. 모든 사실 뒤에 감상을 붙이지 마라.
- 경험에서는 관찰할 대상과 이미 있는 행동에 머물 수 있게 하라. 없어도 되는 장면을 창작해 속도를 늦추지 마라.
- 반론에서는 무엇에 응답하는지와 답의 범위를 선명하게 하라. 전환을 연결어 하나에만 맡기지 마라.
- 결말에서 앞의 사물이 돌아온다면 그 사이 달라진 관점이 원고에 있는지 확인하라. 새 깨달음을 보태는 대신 이미 도달한 대상이나 생각에서 멈출 수도 있다.

구간마다 긴 문장과 짧은 문장의 밀도를 달리할 수 있다. 긴 호흡 뒤의 짧은 말이 강조가 되기도 하고, 긴 문장 둘이 이어지며 머무름을 만들기도 한다. 짧은 문장들의 단절이 필요한 자리도 있다. 모든 문단이 같은 높낮이를 그리지 않게 하라.

사진·표·인용이 있으면 사실과 소속 절·캡션의 대응을 유지하라. 배치까지 고정하라는 조건이 없다면 본문 문단을 합치거나 나눈 뒤 연결을 확인하라. 배치 변경은 사용하는 파일 도구의 실제 기능 안에서 수행하고, 텍스트만 보았다면 조판이나 도판 배치를 검증했다고 하지 마라.

## 장문과 단문을 판단하는 질문

긴 문장:

- 각 절이 앞의 내용을 발전시키거나 시선을 다음 대상으로 옮기는가.
- 주어·시간·조건·중심 대상을 끝까지 따라갈 수 있는가.
- 독자가 끝까지 기다릴 이유와 도착점이 있는가.
- 연결어가 늘어난 만큼 관계가 선명해졌는가. 나열을 길이로 가린 것은 아닌가.
- 원문에 없던 동시성·원인·필연을 만들지는 않았는가.

짧은 문장:

- 초점·멈춤·판단·단절 가운데 실제로 맡는 일이 있는가.
- 앞 문장을 되풀이하는 요약이나 과장된 명언이 되지는 않았는가.
- 이어야 할 관찰을 잘라 낭독이나 의미의 흐름을 끊지는 않았는가.

감정과 수식을 절제하면서도 문장은 길게 흐를 수 있다. 담백함은 그런 선택까지 포함한다. 설명 둘을 합친 문장이 정확하더라도 문학적 효과는 작을 수 있으니, 글자 수·단문 비율·쉼표 수·장단 교대 횟수로 그 효과를 판단하지 마라.

## 첫 번째 검수: 의미 보존

수정문을 원문과 대조하라. 문장 대응이 깨졌다면 문단·구간 단위로 빠짐없이 추적하라.

| 구분 | 확인할 것 |
| --- | --- |
| 사실과 범위 | 인물·역할·행동·수량·수치·날짜·조건·부정·예외 |
| 시간과 인과 | 실제 순서·지속·반복·완료 여부, 새 동시성·원인·필연의 유무 |
| 앎과 정서 | 관찰·전언·추측·단정의 강도, 타인의 내면·화자의 감정·모르는 점 |
| 주장 | 서로 다른 주장의 누락, 효과를 행동·의도로 바꾸었는지 |
| 보호 요소 | 인용·코드·식·URL·서지·표의 값·지정 문장과 구조 |

새 장면이 드러나면 우선 되돌려라. 이 검사는 원문과의 일치 검사이며 외부 사실의 진위를 입증하지 않는다.

## 두 번째 검수: 문학적 효과

의미 검사와 별도로 원문과 수정문을 문단째 비교하고, 이어서 구간·글 전체를 읽어라.

| 구분 | 비교할 것 |
| --- | --- |
| 초점 | 무엇을 보는지 더 선명해졌는가. 수식이 대상을 가리지는 않는가 |
| 서사적 움직임 | 관찰·행동·생각이 이어지는 순서와 도착점이 읽히는가 |
| 호흡 | 장문은 지속·누적·이동을, 단문은 초점·멈춤 등을 실제로 수행하는가 |
| 높낮이 | 구간에 따라 속도와 밀도가 달라지는가. 장단 배열을 반복하는 공식이 되었는가 |
| 이미지와 반복 | 원고에 있는 대상들이 연결되는가. 반복이 새 관계나 관점을 드러내는가 |
| 목소리와 장르 | 작업 전의 목소리 기준과 글의 목적을 지키는가. 일부 문장만 돌출하지 않는가 |

수식어·동의어·연결어만 달라졌다면 문단이 무엇에서 출발해 무엇에 도착할지부터 다시 고르라. 바꾸지 않은 문장이 더 좋은 경우는 인정하되, 윤문 전체가 조사 교정에 머문 경우와는 구별하라. 의미 검사를 통과하거나 많은 문장을 고쳤다는 사실, 장단을 번갈아 놓은 횟수만으로 문학성을 입증하지 마라.

실제로 낭독하거나 음성 도구를 사용했다면 그 범위에서 소리의 걸림을 확인할 수 있다. 텍스트를 읽은 일만으로 낭독 검증을 했다고 보고하지 마라. 비교한 안이나 검수 기록은 요청받은 경우에만 간단히 보여 주어라.
