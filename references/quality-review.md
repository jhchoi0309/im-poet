# 의미와 문학적 효과의 검수

0.8.1에서는 원문에서 윤문으로, 윤문에서 원문으로 두 방향을 확인한 다음 문장과 글 전체의 효과를 읽는다. 의미가 어긋나면 문학적 선호와 별개로 기록한다. 어느 구절에서 시선이 옮겨 갔고 어느 말에서 제 속도를 찾았는지 원문과 나란히 놓고 짚는다.

## 먼저 확인할 의미

행위자와 행동, 날짜와 수량, 시간의 순서와 인과, 조건과 부정, 전언과 추측의 주체를 대조한다. 누가 무엇을 알고 말하는지도 의미에 포함한다. 문자열이 남았어도 명제가 달라질 수 있고, 표현이 크게 달라져도 명제는 지켜질 수 있다. 의도하지 않은 변경은 본문부터 고친다.

원문의 독립된 주장, 관찰과 예시, 반론을 새 구절에 연결한다. 단정이 바뀌기 쉬운 문장은 **주체 / 말하는 내용 / 확신이나 당위 / 기준 시점과 범위** 순으로 읽는다. 서두와 결말에 같은 내용이 나오면 두 군데 모두 본다. 문단 수를 맞추었어도 빠진 요소가 있으면 의미 검수에서 남은 문제로 표시한다. 외부 근거를 실제로 확인하지 않은 경우 확인 상태는 '원문 대조만 수행'이다.

## 문학적 효과를 나누어 읽기

| 기준 | 판단을 뒷받침할 질문 |
| --- | --- |
| 원문 의미와 사실 | 무엇이 유지됐고 어느 조건이나 관점이 달라졌는가 |
| 원문의 문체 | 요청한 범위의 어휘와 말의 높이, 서술 태도가 남았는가 |
| 어휘의 정확성 | 대상과 동작에 어울리는 자연스러운 결합인가 |
| 운율과 호흡 | 긴 호흡과 멈춤이 각각 맡은 일이 있는가 |
| 비유 | 원문 대상의 관계를 선명하게 하며 새 사실을 만들지 않는가 |
| 정서 | 감정의 주체와 크기, 표현의 거리가 원고에 맞는가 |
| 심상 | 원고에 있는 감각과 개념이 구체적으로 연결되는가 |
| 구성과 응집 | 절마다 다른 속도와 역할이 있고 전환을 따라갈 수 있는가 |
| 장르와 독자 | 독자가 이해하거나 해야 할 일이 흐려지지 않았는가 |
| 경제성과 여백 | 같은 결론의 해설을 덜고 필요한 반복은 남겼는가 |
| 상투성과 인위성 | 장치가 문맥의 필요에서 나왔는가, 다른 공식으로 치환했는가 |
| 전체의 완성도 | 좋은 구절들이 서로 받쳐 주며 결말까지 목적을 수행하는가 |

모든 원고에 열두 질문을 같은 무게로 적용하지 않는다. 해당하는 항목에서 근거를 찾고 판단할 수 없는 부분은 남겨 둔다. 비유가 없는 기술 글을 낮게 평가하거나, 의도적인 거친 표현을 유창하지 않다는 이유로 교정하지 않는다. 한국어의 형태와 담화 기능, 독자의 취향과 실제 오류를 구별한다.

미완성 문장도 앞뒤가 연결되며 단절을 의도할 수 있다. 연결되는 대상과 효과가 있는지 읽는다. 문장 끝이 잘렸거나 지시 대상이 사라진 오류는 여운으로 정당화하지 않는다. 높은 AI 점수도 이 검사를 대신하지 않는다.

전면 재서술 결과가 더 읽기 쉬워졌더라도 문학적 변화가 없다면 그 둘을 따로 기록한다. 제목을 가리고 마지막 두 문장을 바꾸어 붙여도 통한다면 글에서만 생기는 뜻이 약한지 점검한다. 다만 보편적 문장을 썼다는 사실만으로 삭제하지 말고, 원래 있던 논지와 정서의 역할을 먼저 확인한다.

## 변경점을 요청받았을 때

원문과 수정문, 변화의 역할을 짧은 표로 보여 준다. 실제로 바뀐 구절을 고르고, 유지한 구절은 보존의 판단으로 설명한다. 전면 재서술의 문단을 원문 한 문장에 억지로 대응시키지 않는다. 요청하지 않은 자기평가와 사고 과정은 출력하지 않는다.

## 보조 도구가 확인하는 것

```bash
python3 scripts/review_rewrite.py original.txt --rewrite revised.txt
python3 scripts/review_rewrite.py original.txt --rewrite revised.txt --sample sample.txt
python3 scripts/review_rewrite.py original.txt --rewrite revised.txt --protected literals.json
```

Python 3.10 이상에서 실행한다. `literals.json`은 원문에 있는 보호 문자열의 JSON 배열이다. 보고서는 표면적인 길이와 종결, 지정 문자열의 존재를 확인한다. 본문의 내용을 외부로 보내거나 의미 일치, 문학성을 판정하지 않는다. 형태소 분석과 실제 낭독 운율도 측정하지 않는다.

종료 코드 0은 선택한 기계 검사에서 위반을 발견하지 못했다는 뜻이다. 원문만 분석하면 출력 검사는 수행하지 않는다. 코드 1은 금지 문자 또는 지정 문자열 누락, 코드 2는 입력이나 설정 오류다. 코드 0을 좋은 윤문으로 읽지 않는다.

## 개정 효과를 비교하는 방법

원문 A, 이전 지침 B, 새 지침 C, 고정한 일반 교정 D를 같은 모델과 설정, 요청으로 비교한다. 개발 예문과 분리된 입력을 사용하고 작성 단계에 기대 답을 주지 않는다. 표기를 가리고 순서를 섞되 원문 자체는 알아볼 수 있다는 한계를 남긴다.

의미 검수와 문학적 선호를 분리하고, 의미 실패를 제외해 유리한 결과만 만들지 않는다. 전문가와 일반 독자를 나누며, 가능하면 세 명 이상의 독립 평가자가 구체적인 이유를 남긴다. 쌍별 선호와 불일치, 표본의 조건 및 불확실성을 보고한다. AI 평정과 같은 모델의 반복 응답을 독립적인 사람 평가로 세지 않는다.

[연구 적용](research-0.8.0.md)의 판독 범위와 [수정의 조건과 반례](revision-decisions.md)를 함께 읽는다. 작은 개발 실험은 일반적인 성능 향상의 증거로 확대하지 않는다.
