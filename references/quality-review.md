# 검수와 비교의 범위

윤문 결과를 원문과 나란히 읽으라. 의미 보존과 문학적 효과는 서로 대신할 수 없는 판단이다. 좋은 문장처럼 보인다는 이유로 의미 변화를 넘기지 말고, 의미가 같다는 이유로 문학적으로 개선됐다고 말하지 마라.

## 나누어 살필 기준

| 기준 | 비교할 것 |
| --- | --- |
| 의미와 범위 | 사실, 행위자, 수량과 시간, 조건과 부정, 주장 강도와 누락 |
| 문학적 변화 | 중심 대상과 서술, 이미지의 관계, 시선과 사유의 움직임 |
| 자연스러움 | 어휘의 결합, 불필요한 해설, 억지스러운 질문과 추측 |
| 요청한 문체 | 명시한 말투와 종결, 참고 샘플의 적용 가능한 특성, 의도적인 반복 |
| 목적 적합성 | 독자가 알아야 할 것과 해야 할 일이 보이며 장르의 기능을 지키는가 |

한 가지 종합 점수로 의미 손실을 문학성의 이득과 상쇄하지 마라. 취향의 차이와 의미 오류는 따로 기록한다.

구절을 끊어 여운을 남겼다면 앞 문장과의 문법적 연결이 읽히는지 보라. 미완성이라는 사실만으로 문학적인 것은 아니다. 기술 기록에서는 같은 사실을 다시 장식한 문장과 불필요한 대비를 덜 수 있다. 의도적인 단절과 실제 반론을 함께 지우지는 마라. 결말에서 같은 인식을 여러 비유와 해설로 거듭 풀었다면 각 구절이 새로 더하는 뜻을 비교하라. 새 뜻 없이 같은 자리에 머무는 표현은 중심 이미지로 모으고, 의도한 반복의 정서는 남긴다.

## 변경점을 설명할 때

요청받은 경우에 실제 바뀐 구절을 고르라. 원문, 수정문, 변화의 역할을 보여 주고 의미와 보호 요소에 관한 판단을 필요한 만큼 덧붙인다. 단순히 '더 아름답다'고 평가하지 말고 어떤 대상을 먼저 보게 되었는지와 어떤 호흡을 만들었는지 말하라. 변경하지 않은 구절은 보존의 판단으로 구별한다.

한 문장씩 대응하지 않는 전면 재서술은 구간과 문단으로 비교한다. 문장별 변경표를 만들려고 원래 구조에 다시 맞추지 마라. 수정 이유는 검토 가능한 편집 근거이며 숨은 사고 과정이나 탈락한 모든 안의 목록이 아니다.

## 보조 도구

Python 3.10 이상이 있으면 다음 도구를 사용할 수 있다. 입력 파일을 수정하지 않고 본문을 보고서에 그대로 복사하지 않는다.

```bash
python3 scripts/review_rewrite.py original.txt --rewrite revised.txt
python3 scripts/review_rewrite.py original.txt --rewrite revised.txt --sample sample.txt
python3 scripts/review_rewrite.py original.txt --rewrite revised.txt --protected literals.json
```

`literals.json`은 정확히 남겨야 하는 문자열의 JSON 배열이다. 예를 들어 `["3.3 V", "11월 3일 18시"]`처럼 지정할 수 있다. 목록에 넣은 문자열은 원문에도 있어야 한다. 보고서는 목록의 번호로 발견 여부를 알려 주며, 그 내용과 횟수, 순서가 모두 보존됐다고 인증하지 않는다. 보호 요소에 금지 문자가 있으면 이 자동 검사는 실패하고 정확한 재현과 출력 금지의 충돌을 별도로 판단해야 한다.

문장 경계와 종결 분류는 표면 규칙으로 계산한 근사치다. 인용과 줄바꿈, 약어와 문장부호에 영향을 받으며 한국어 형태소 분석이나 확신의 강도 측정이 아니다. 샘플 분포와 달라졌다는 이유로 실패시키거나 일괄 수정하지 않는다. 원문을 읽고 적용 가능한 차이인지 판단하라.

종료 코드 0은 선택한 기계 검사에서 위반이 발견되지 않았다는 뜻이다. 원문만 분석하면 출력 검사는 수행되지 않는다. 종료 코드 1은 금지 문자나 명시한 보호 구절의 누락, 2는 입력이나 설정 오류다. 어떤 결과도 의미 일치와 문학성을 판정하지 않는다.

## 실제 효과를 비교하려면

같은 모델과 설정, 같은 요청과 원문을 이전 지침과 새 지침에 별도 문맥으로 전달하라. 예문과 겹치지 않는 평가 원고를 사용하고, 기대 답과 판정 기준은 작성자에게 주지 마라. 출력의 순서를 섞어 원문과 함께 읽고 위 기준을 각각 살핀다. 같은 문서를 여러 번 실행했다면 반복 횟수와 실제 설정, 판정 불일치도 남긴다.

표본 수와 평가자, 사용 모델을 확인하지 못한 경우에는 그대로 기록하라. 작은 표본과 같은 작성자의 자기 평가를 독립적인 품질 검증으로 확대하지 마라. 이 도구와 절차는 탐지기 우회나 AI 작성 여부 판별을 위한 것이 아니다.
