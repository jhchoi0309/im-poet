# 장르별 적용

문학성의 밀도와 글의 기능을 함께 결정한다. 아래는 상한선이 아니라 출발점이다. 사용자가 원하는 강도를 우선하되 사실 보존은 그대로 지킨다.

| 글 | 문학적으로 다듬을 부분 | 끝까지 남길 정보 |
| --- | --- | --- |
| 에세이·사진 글 | 사물의 재등장, 시선의 이동, 독백, 여백과 멈춤 | 실제 경험·시간·감정·모르는 부분 |
| 소설 원고 | 초점화, 대화의 말투, 장면의 속도, 반복되는 사물 | 인물·시점·사건·관계; 각색 요청 없이 새 사건을 추가하지 않음 |
| 메시지·편지 | 말의 거리, 부드러운 권유, 짧은 호흡과 여운 | 전달 목적·상대·약속·의사; 원문에 없는 친밀함이나 공동 기억을 넣지 않음 |
| 자기소개서 | 경험의 구체적 행동, 판단이 드러나는 순서, 절제된 반복 | 지원자와 팀의 역할·기여·성과·수치·한계·문항 적합성 |
| 안내문 | 의미 단위가 분명한 어순과 문장, 필요한 여백 | 언제·어디서·누가·무엇을·어떻게, 기한·의무·예외 |
| 보고서·학술 설명 | 명료한 동사, 문단의 전환, 필요한 병치 | 근거·인용·범위·불확실성·논리·결론 |
| 기술 설명 | 동작의 순서, 개념의 관계, 용어를 유지하는 리듬 | 수치·단위·조건·식·코드·인과·기술적 정의 |
| 시로 바꾸기 | 행·연의 분절, 이미지의 전환, 소리와 반복 | 원문의 사실과 관점; 자유 각색 허락이 있어야 새 장면 창작 가능 |

## 강도 선택

- 가볍게: 뜻·구조·말투를 유지하고 어순·조사·호흡을 다듬는다.
- 기본: 중심 사물과 반복, 관찰과 생각의 이동을 살리며 문장과 문단의 속도를 조절한다. 긴 문장과 짧은 문장의 역할을 나누고 원래 산문 형식을 유지한다.
- 강하게·전면 재서술: 어순·문장 경계·절 안의 문단 구획·정보 제시 순서를 적극적으로 재구성한다. 원문 문장·문단과의 일대일 대응은 기본값이 아니다. 실제 사건의 순서·논지·인용·보호 지정 문장·명시된 구조는 지킨다. 원고 전체의 절 순서를 뒤바꾸는 대규모 개편은 요청 범위를 확인한다. 강도가 높아도 사실이나 주장을 추가하지 않는다.

문학적 재서술이라는 요청은 위 범위의 전달 방식 재구성을 포함한다. 문단 변경에 별도 허락이 없다는 이유로 어휘 교체에 머물지 않는다. 사용자가 가벼운 교정이나 문단 고정을 지정하면 그 제한을 우선한다. 담백하게 해 달라는 요청은 감정과 수식의 절제로 해석하고, 단문만 쓰라는 뜻으로 축소하지 않는다.

추상적인 글도 다룬다. 구체적 사례가 없다고 작업을 거절하거나 장면을 요구하지 않는다. 정확한 뜻을 남긴 채 명사 나열을 풀고 어순·병치·종결을 바꾼다. 고유한 논증을 잃어야만 압축할 수 있다면 원문을 남기거나 내용 편집 요청 범위 안에서만 정리한다.

## 혼합 원고

기술적 본문에 짧은 에세이 서문이 붙어 있다면 부분마다 밀도를 달리한다. 표·목록이 행동 요건이나 수치를 전달하면 형식을 유지한다. 전체를 같은 감상적 목소리로 덮지 않는다. 제한이 많은 글에서도 가능한 문체 변화를 찾되, 이미 정확한 핵심 문장을 그대로 두는 선택을 허용한다.
