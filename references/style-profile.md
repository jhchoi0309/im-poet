# 원고와 샘플에서 문체의 기준 만들기

전면 재서술의 기본은 뜻을 남기고 표현과 구성을 새롭게 고르는 일이다. 사용자가 자신의 글이나 승인한 문장을 문체 기준으로 지정하면 그 범위에서 참고하라. 기존 원고의 문체를 반드시 유지하는 작업과 구별하고, 매번 샘플 제출을 요구하지 마라.

## 무엇을 읽을 것인가

현재 요청과 글의 목적을 먼저 읽으라. 참고 샘플에서는 다음 특성을 필요한 만큼 살피라.

| 축 | 관찰할 것 | 오해하기 쉬운 부분 |
| --- | --- | --- |
| 말의 높이 | 존대와 문어, 대화와 독백의 거리 | 어미를 다양하게 한다며 높임을 섞음 |
| 호흡 | 무엇을 길게 잇고 어디에서 멈추는가 | 장문 비율을 맞추는 일로 바꿈 |
| 어휘와 비유 | 구체적인 동사, 전문어, 이미지의 관계 | 샘플의 소재와 고유 구절을 복제함 |
| 시선 | 사물에서 생각으로 가는가, 판단에서 사례로 가는가 | 모든 글에 같은 전개를 강제함 |
| 정서와 인식 | 감정을 얼마나 드러내며 모름을 어떻게 남기는가 | 사실을 전부 추측형으로 낮춤 |
| 반복과 거침 | 의도적인 재등장과 끊김이 하는 일 | 불규칙하다는 이유만으로 교정함 |

관찰마다 실제 구절의 근거를 두라. 샘플이 짧거나 특정 장르 한 편뿐이면 그 한계를 남기고 다른 장르에 엄격하게 적용하지 마라. 여러 곳에서 반복된 특징과 한 번만 나타난 선택을 구별하라. 관찰 수에 임의의 기준을 정해 고정 문체를 판정하지 마라.

## 짧은 내부 프로필

필요하면 다음 정도로 정리할 수 있다. 사용자에게 요청 없이 출력할 형식은 아니다.

- 적용 범위: 이번 에세이의 본문, 안내문과 직접 인용은 별도.
- 관찰: 대상을 충분히 본 뒤 판단하며 감정어를 드물게 쓴다.
- 근거: 사용자가 제공한 문장의 실제 구절.
- 적용: 관찰과 판단이 이어지는 순서를 새로 설계한다.
- 불확실성: 샘플 한 편만으로 다른 글의 종결과 비유까지 정하지 않는다.

샘플을 통째로 따라 쓰지 말고 관찰한 관계를 다른 원고의 내용으로 구현하라. 샘플의 바다와 겨울을 원고에 없는 장소나 계절로 추가하지 마라. 인용문과 명시한 일정, 의무는 샘플의 말투보다 먼저 지킨다.

## 보호와 재구성의 균형

사용자가 '의도적인 반복을 살려 달라'고 했다면 그 반복의 역할을 유지하라. '문체도 자유롭게 바꿔 달라'고 했다면 같은 어휘와 문장 경계에 묶이지 마라. 현재의 구체적인 지시가 일반적인 문체 관찰보다 우선한다.

짧은 샘플에서 나타난 표현을 금지어와 필수어의 목록으로 만들지 마라. 표면적 분포는 다시 읽을 단서다. 원고와 수정문이 같은 길이와 어미 비율을 가져야 하는 것은 아니다. `scripts/review_rewrite.py`는 이 차이를 읽는 보조 도구이며 개인 문체를 학습하거나 인증하지 않는다.

샘플과 내부 프로필은 이번 작업에 필요한 범위에서 사용한다. 자동으로 다른 서비스에 전송하거나 스킬에 누적하지 않는다. 사용자가 프로필 파일을 요청했다면 근거와 적용 범위, 미확인 부분을 함께 기록한다.
